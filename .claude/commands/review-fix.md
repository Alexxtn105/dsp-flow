Выполни цикл «ревью → фикс → повторное ревью» до полного устранения дефектов:

1. **Ревью**: Запусти субагент-ревьюера (general-purpose) для проверки ВСЕХ изменённых/новых файлов. Ревьюер должен проверить:
   - Корректность алгоритмов и логики
   - Обработку краевых случаев (null, NaN, пустые массивы, переполнение)
   - Соответствие паттернам проекта (стиль, типы, именование)
   - Полноту регистрации (index, constants, i18n, иконки)
   - Покрытие тестами
   - Уязвимости безопасности

   Ревьюер возвращает список дефектов с уровнями: 🔴 Critical, 🟡 Medium, 🟢 Minor.

2. **Фикс**: Исправь ВСЕ найденные дефекты (Critical и Medium обязательно, Minor по возможности).

3. **Проверка**: Запусти `npm run lint` и `npm run test`. Убедись что всё проходит.

4. **Повторное ревью**: Запусти ревьюера снова для проверки фиксов. Если найдены новые дефекты — вернись к шагу 2.

5. **Завершение**: Когда ревьюер подтвердит "All clear" — цикл окончен. Выведи итоговый отчёт:
   - Сколько итераций потребовалось
   - Сколько дефектов было найдено и исправлено по категориям
   - Финальный статус lint/test
