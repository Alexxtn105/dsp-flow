# DSP Flow Editor

Визуальный редактор графов цифровой обработки сигналов (DSP). Drag & drop интерфейс для построения цепочек обработки сигналов с обработкой в реальном времени прямо в браузере.

**[Live Demo](https://alexxtn105.github.io/dsp-flow/)**

## Возможности

- **Визуальное программирование** — создание схем обработки сигналов без кода через drag & drop
- **Обработка в реальном времени** — Web Audio API, поблочная обработка (1024 сэмпла, Float32Array)
- **Три режима работы** — реальное время, ручной (пошаговый), файловый (WAV)
- **25 DSP-блоков** — генераторы, фильтры, анализаторы, детекторы, математика, визуализация
- **Плагинная архитектура** — каждый блок — независимый плагин с метаданными и процессором
- **4 типа визуализации** — осциллограф, спектр, водопад, фазовое созвездие
- **Валидация графа** — проверка совместимости сигналов (real/complex), обнаружение циклов
- **Сохранение/загрузка** — localStorage с автосохранением (debounce 5 сек)
- **Светлая/тёмная тема**

## Технологический стек

- **React 19** + **React Flow** (`@xyflow/react`) — UI и node-based редактор
- **Vite 7** — сборка и dev-сервер
- **Web Audio API** — обработка и воспроизведение аудио
- **Vitest** — тестирование (177 тестов, 13 файлов)
- **ESLint 9** — линтинг (flat config)
- **GitHub Actions** — CI/CD с деплоем на GitHub Pages

## Установка и запуск

**Требования:** Node.js >= 18, npm >= 8

```bash
npm install          # Установка зависимостей
npm run dev          # Dev-сервер → http://localhost:5173
npm run build        # Продакшн-сборка → /dist
npm run preview      # Предпросмотр сборки
npm run lint         # Линтинг
npm run test         # Запуск тестов
```

## Использование

1. **Добавление блоков** — перетащите блок из левой панели на холст
2. **Соединение** — перетащите от выходного порта к входному (типы real/complex проверяются автоматически)
3. **Настройка** — двойной клик по блоку для редактирования параметров
4. **Запуск** — нажмите Play для обработки в реальном времени или используйте ручной режим
5. **Визуализация** — откройте окна осциллографа/спектра для отслеживания сигнала
6. **Сохранение** — Ctrl+S или кнопка сохранения (автосохранение каждые 5 сек)

### Управление холстом

- **Перемещение** — зажмите ЛКМ на пустом месте
- **Масштабирование** — колесо мыши
- **Удаление** — выделите элемент и нажмите Delete

```
│   ├── WavFileService.js    # Работа с WAV-файлами
│   ├── initPlugins.js       # Инициализация плагинов
│   └── plugins/             # 25 DSP-плагинов по категориям
│       ├── _shared/         # FFTUtils, FilterDesign, WindowFunctions

│       ├── filters/         # Фильтры (6)
│       ├── analysis/        # БПФ, спектроанализ (3)
│       ├── detectors/       # Частотный/фазовый детекторы (2)

│       ├── visualization/   # Осциллограф, водопад и т.д. (3)
│       └── output/          # Динамик (1)
├── components/
│   ├── dsp/                 # BlockNode, DSPEditor, edges
│   ├── visualization/       # 4 вида визуализации + менеджер окон
│   ├── dialogs/             # Диалоги (параметры, сохранение, загрузка, настройки)
│   ├── layout/              # Header, Footer, Toolbar, ControlToolbar
│   └── common/              # Dialog, ErrorBoundary, Icons
├── hooks/                   # useTheme, useSchemeStorage, useAutoSave,
│                            # useDialogManager, useDSPSimulation
├── contexts/                # DSPEditorContext, ThemeContext

├── utils/                   # constants, helpers

```

## Тесты

```bash
npm run test                                      # Все 177 тестов
npx vitest run tests/plugins/generators.test.js   # Один файл
```

Структура тестов повторяет `src/engine/`:
- `tests/engine/` — PluginRegistry, GraphCompiler, DSPProcessor, WavFileService
- `tests/plugins/` — generators, filters, analysis, detectors, math, visualization, shared
- `tests/integration/` — сквозные сценарии обработки сигналов
