# Перспективные плагины для dsp-flow

Текущее количество плагинов: **59**. Последнее обновление: 2026-03-09.

## Высокий приоритет

### Генераторы сигналов
| Блок | Описание |
|------|----------|
| SquareWaveGenerator | Меандр с настраиваемой скважностью |
| TriangleWaveGenerator | Треугольный сигнал |
| SawtoothWaveGenerator | Пилообразный сигнал |
| ImpulseGenerator | Единичный импульс / периодическая последовательность |
| ChirpGenerator | ЛЧМ/экспоненциальная частотная развёртка |

### Адаптивные фильтры
| Блок | Описание |
|------|----------|
| LMSFilter | Адаптивный фильтр (метод наименьших средних квадратов) |

### Модели каналов
| Блок | Описание |
|------|----------|
| AWGNChannel | Канал с аддитивным белым гауссовым шумом (SNR в дБ) |

### Цифровые модуляции
| Блок | Описание |
|------|----------|
| QAMModulator | 16/64/256-QAM модулятор |
| QAMDemodulator | QAM демодулятор (hard/soft decision) |

### Измерения
| Блок | Описание |
|------|----------|
| SNRMeter | Измеритель отношения сигнал/шум |
| BERCounter | Счётчик битовых ошибок |
| Histogram | Гистограмма распределения амплитуд (визуализация) |

## Средний приоритет

### Адаптивные фильтры и эквалайзеры
| Блок | Описание |
|------|----------|
| RLSFilter | Рекурсивный МНК (быстрая сходимость, O(N²)) |
| ZFEqualizer | Линейный эквалайзер (Zero-Forcing) |
| PIDController | ПИД-регулятор для контуров управления |

### Модели каналов
| Блок | Описание |
|------|----------|
| FadingChannel | Рэлеевское/Райсовское замирание |
| FrequencySelectiveChannel | Частотно-селективный канал (линия задержки с отводами) |

### Цифровые модуляции
| Блок | Описание |
|------|----------|
| OFDMModulator | OFDM модулятор (IFFT, циклический префикс) |
| OFDMDemodulator | OFDM демодулятор (FFT, эквализация) |

### Аудио-обработка
| Блок | Описание |
|------|----------|
| Compressor | Динамический компрессор (threshold, ratio, attack/release) |
| Equalizer | Параметрический эквалайзер (multi-band) |
| Echo | Эхо/задержка с обратной связью |
| Reverb | Реверберация (архитектура Шрёдера) |

### Анализ и визуализация
| Блок | Описание |
|------|----------|
| Spectrogram | Спектрограмма (STFT, time-frequency) |
| PeakDetector | Детектор пиков (локальные максимумы) |
| PitchDetector | Детектор высоты тона (автокорреляция/YIN) |
| InstantaneousFrequency | Мгновенная частота (через аналитический сигнал) |
| PowerMeter | Измеритель мощности (RMS, пиковая, средняя) |

### Ресемплинг
| Блок | Описание |
|------|----------|
| PolyphaseFilter | Полифазный фильтр для эффективной децимации/интерполяции |
| FractionalDelay | Дробная задержка (Лагранж/Фарроу) |

### Прочее
| Блок | Описание |
|------|----------|
| Quantizer | Квантователь (эмуляция АЦП, фиксированная точка) |
| SampleAndHold | Выборка-хранение |

## Низкий приоритет

| Блок | Описание |
|------|----------|
| FSKModulator / FSKDemodulator | Частотная манипуляция |
| CarrierRecovery | Петля Костаса (восстановление несущей) |

| PhasePortrait | Фазовый портрет (траектория в пространстве состояний) |
| GroupDelayPlot | Визуализация групповой задержки фильтра |

## Рекомендуемый порядок реализации

1. **Фаза 1** — базовые генераторы (Square, Triangle, Sawtooth, Impulse, Chirp) + AWGNChannel + SNRMeter, BERCounter, Histogram
2. **Фаза 2** — LMSFilter, PIDController, QAM модулятор/демодулятор, Spectrogram
3. **Фаза 3** — OFDM, RLSFilter, эквалайзер, аудио-эффекты
