| | |
|---|---|
| **ID** | `integrator` |
| **Иконка** | `dsp-integrate` |
| **Вход → Выход** | real → real |

Численное интегрирование сигнала.

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `resetOnOverflow` | false | Сброс при переполнении |

### Алгоритм

## Смеситель (Frequency Shift)

| | |
|---|---|
| **ID** | `mixer` |
| **Иконка** | `dsp-mixer` |
| **Вход → Выход** | real → complex |

Перенос спектра на заданную частоту.

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `shiftFrequency` | 1000 | Частота сдвига, Гц (+ вверх, − вниз) |

### Алгоритм

Умножение на комплексную экспоненту: `y(t) = x(t)·exp(j·2π·f·t)`.

- Для real-входа: `I = x·cos(φ)`, `Q = x·sin(φ)`
- Для complex-входа: полное комплексное умножение

Фаза нормализуется по модулю 2π.

## Компаратор

| | |
|---|---|
| **ID** | `threshold` |
| **Иконка** | `dsp-threshold` |
| **Вход → Выход** | real → real |

Пороговая бинаризация сигнала (триггер Шмитта).

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `threshold` | 0 | Порог срабатывания |
| `outputHigh` | 1 | Значение при превышении |
| `outputLow` | 0 | Значение ниже порога |
| `hysteresis` | 0 | Ширина зоны гистерезиса |

### Алгоритм

С гистерезисом:
- Переход HIGH→LOW: `x < threshold - hysteresis/2`
- Переход LOW→HIGH: `x > threshold + hysteresis/2`

| | |
|---|---|
| **ID** | `gain` |
| **Иконка** | `dsp-gain` |
| **Вход → Выход** | real → real |

Масштабирование сигнала.

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `gain` | 1.0 | Коэффициент усиления |

## Коррелятор

| | |
|---|---|
| **ID** | `correlator` |
| **Иконка** | `dsp-correlator` |
| **Вход → Выход** | real (×2) → real |
| **Входы** | «Вход 1», «Вход 2» |

Взаимная корреляция двух сигналов.

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `normalize` | true | Нормализация коэффициента корреляции |
| `maxLag` | 0 | Максимальный лаг (0 = chunkSize-1) |

### Алгоритм

`R_xy(τ) = Σ (x[n] - μx)·(y[n+τ] - μy) / √(E_x · E_y)`

Выход центрирован: лаг 0 расположен в середине буфера (`chunkSize/2`), положительные и отрицательные лаги — симметрично. При `normalize = false` — raw-корреляция без вычитания средних и нормализации.
