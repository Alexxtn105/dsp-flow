# Генераторы

Источники сигналов — блоки без входов, формирующие выходной сигнал.

## Синусный генератор

| | |
|---|---|
| **ID** | `sine-generator` |
| **Иконка** | `dsp-sine` |
| **Вход → Выход** | — → real |

Генерация синусоидального сигнала с заданной частотой, амплитудой и начальной фазой.

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `frequency` | 1000 | Частота, Гц |
| `amplitude` | 1.0 | Амплитуда |
| `phase` | 0 | Начальная фаза, градусы |

### Алгоритм

Фазовый аккумулятор с инкрементом `Δφ = 2π·f/Fs`. На каждом сэмпле: `y[n] = A·sin(φ + φ₀)`, фаза нормализуется по модулю 2π для предотвращения потери точности.

## Референсный синусный генератор (NCO)

| | |
|---|---|
| **ID** | `ref-sine-generator` |
| **Иконка** | `dsp-ref-sine` |
| **Вход → Выход** | real (×2) → complex |
| **Входы** | «Частота (Гц)», «Фаза (рад)» |

Генератор с управлением по частоте (NCO — Numerically Controlled Oscillator). Принимает мгновенную частоту и фазовый сдвиг с внешних входов.

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `frequency` | 1000 | Базовая частота, Гц |
| `amplitude` | 1.0 | Амплитуда |
| `phase` | 0 | Начальная фаза, градусы |
| `controllable` | true | Использовать входы для управления |

### Алгоритм

Выход — аналитический сигнал: `I = sin(φ)`, `Q = cos(φ)`. Мгновенная частота берётся из первого входа, фазовый сдвиг — из второго. Фаза нормализуется для предотвращения дрейфа.

## Генератор шума

| | |
|---|---|
| **ID** | `noise-generator` |
| **Иконка** | `dsp-noise` |
| **Вход → Выход** | — → real |

Генерация шума трёх типов.

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `noiseType` | `'white'` | Тип: `white`, `pink`, `brown` |
| `amplitude` | 1.0 | Амплитуда |

### Алгоритм

- **Белый**: равномерное распределение `[-1, 1]`
- **Розовый**: IIR-фильтр по алгоритму Paul Kellet (7 коэффициентов), спектр ~1/f
- **Красный (броуновский)**: интеграция белого шума с ограничением по насыщению

## АМ/ЧМ/ФМ модулятор

| | |
|---|---|
| **ID** | `amfmpm-modulator` |
| **Иконка** | `dsp-modulator` |
| **Вход → Выход** | real → real |

Модулятор с выбором типа модуляции.

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `modulationType` | `'AM'` | Тип: `AM`, `FM`, `PM` |
| `carrierFrequency` | 10000 | Частота несущей, Гц |
| `modulationIndex` | 0.5 | Индекс модуляции |

### Алгоритм

- **АМ**: `s(t) = (1 + m·x(t))·cos(2π·fc·t)`
- **ЧМ**: `s(t) = cos(2π·fc·t + 2π·Δf·∫x(t)dt)` — `m` задаёт девиацию частоты в Гц
- **ФМ**: `s(t) = cos(2π·fc·t + m·x(t))` — `m` задаёт индекс фазовой модуляции в радианах

## PSK модулятор

| | |
|---|---|
| **ID** | `psk-modulator` |
| **Иконка** | `dsp-psk` |
| **Вход → Выход** | — → complex |

Генератор PSK-модулированного сигнала с PRBS-данными.

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `constellation` | `'QPSK'` | Схема: `BPSK`, `QPSK`, `8PSK` |
| `symbolRate` | 1000 | Символьная скорость, символов/с |
| `amplitude` | 1.0 | Амплитуда |

### Алгоритм

Генерирует псевдослучайную последовательность бит через LFSR (32-бит, полином `0x80200003`). Биты маппятся на точки созвездия:
- **BPSK**: 1 бит → `±A` по оси I
- **QPSK**: 2 бита → 4 точки с шагом π/2 (начало π/4)
- **8PSK**: 3 бита → 8 точек с шагом π/4

Каждый символ удерживается `Fs/symbolRate` сэмплов.
