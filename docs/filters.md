## ФНЧ КИХ-фильтр

| | |
|---|---|
| **ID** | `lowpass-fir-filter` |
| **Иконка** | `dsp-lowpass` |
| **Вход → Выход** | real → real |

Фильтр низких частот на основе оконного sinc-метода.

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `order` | 64 | Порядок фильтра (кол-во коэффициентов) |
| `cutoff` | 1000 | Частота среза, Гц |
| `windowFunction` | `'hamming'` | Оконная функция |

### Алгоритм

Коэффициенты: `h[n] = sinc(2π·fc·n/Fs)·w[n]`, где `w[n]` — оконная функция. Свёртка через кольцевой буфер.

## Полосовой КИХ-фильтр

| | |
|---|---|
| **ID** | `bandpass-fir-filter` |
| **Иконка** | `dsp-bandpass` |
| **Вход → Выход** | real → real |

Пропускает полосу частот между `lowCutoff` и `highCutoff`.

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `order` | 64 | Порядок фильтра |
| `lowCutoff` | 1000 | Нижняя частота среза, Гц |
| `highCutoff` | 3000 | Верхняя частота среза, Гц |
| `windowFunction` | `'hamming'` | Оконная функция |

### Алгоритм

Разность двух sinc-фильтров: `h_bandpass = h_highcutoff - h_lowcutoff`.

## БИХ-фильтр

| | |
|---|---|
| **ID** | `iir-filter` |
| **Иконка** | `dsp-iir` |
| **Вход → Выход** | real → real |

IIR-фильтр на основе каскада biquad-секций (Second-Order Sections).

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `filterDesign` | `'butterworth'` | Тип: `butterworth`, `chebyshev1` |
| `filterType` | `'lowpass'` | Тип: `lowpass`, `highpass` |
| `cutoffFrequency` | 1000 | Частота среза, Гц |
| `order` | 4 | Порядок (1–10) |
| `ripple` | 1 | Пульсации в полосе пропускания, дБ (для Чебышева) |

### Алгоритм

1. Расчёт полюсов аналогового прототипа (Баттерворт / Чебышев I)
2. Билинейное преобразование → цифровые biquad-секции
3. ФВЧ — через спектральную инверсию (знакочередование коэффициентов)
4. Нормализация усиления (для Чебышева)

Коэффициенты пересчитываются только при изменении параметров.

## Преобразователь Гильберта

| | |
|---|---|
| **ID** | `hilbert-transformer` |
| **Иконка** | `dsp-hilbert` |
| **Вход → Выход** | real → complex |

Формирование аналитического сигнала (сдвиг на 90°).

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `order` | 64 | Порядок фильтра |
| `phaseShift` | 90 | Фазовый сдвиг, градусы |

### Алгоритм

КИХ-фильтр Гильберта: `h[n] = 2/(π·n)` для нечётных `n`, с оконной функцией. Выход: `I` — задержанный вход, `Q` — выход фильтра Гильберта.

## Фильтр Герцеля

| | |
|---|---|
| **ID** | `goertzel-filter` |
| **Иконка** | `dsp-goertzel` |
| **Вход → Выход** | real → real |

Эффективная детекция одной частоты (одночастотное ДПФ).

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `targetFrequency` | 1000 | Целевая частота, Гц |
| `N` | 256 | Размер блока анализа |

### Алгоритм

Рекуррентное соотношение: `s₀ = x[n] + 2·cos(2π·k/N)·s₁ - s₂`. После N сэмплов вычисляется магнитуда. Вычислительная сложность O(N) vs O(N·log N) для БПФ.

## Децимация / Интерполяция

| | |
|---|---|
| **ID** | `decimator-interpolator` |
| **Иконка** | `dsp-resample` |
| **Вход → Выход** | real → real |

Изменение частоты дискретизации с антиалиасинг-фильтром.

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `mode` | `'decimate'` | Режим: `decimate` (↓) или `interpolate` (↑) |
| `factor` | 2 | Коэффициент |
| `filterEnabled` | true | Включить антиалиасинг-фильтр |

### Алгоритм

- **Децимация**: sinc-ФНЧ (срез = 1/factor) → выборка каждого factor-го сэмпла
- **Интерполяция**: вставка (factor-1) нулей → sinc-ФНЧ (срез = 1/factor)

## CIC-фильтр

| | |
|---|---|
| **ID** | `cic-filter` |
| **Иконка** | `dsp-cic` |
| **Вход → Выход** | real → real |

Каскадный интегратор-гребёнка. Эффективная децимация/интерполяция без умножителей.

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `stages` | 3 | Количество каскадов (1–6) |
| `decimationFactor` | 4 | Коэффициент (2–64) |
| `mode` | `'decimate'` | Режим: `decimate` или `interpolate` |

### Алгоритм

- **Децимация**: N каскадов интеграторов (Fs) → понижение → N каскадов гребёнок (Fs/R)
- **Интерполяция**: N каскадов гребёнок (Fs) → повышение (zero-stuffing) → N каскадов интеграторов (Fs·R)

Усиление CIC = R^N, нормализуется на выходе. АЧХ — sinc^N-форма.
