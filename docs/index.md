## Типы сигналов

| Тип | Формат данных | Описание |
|-----|--------------|----------|
| `real` | `Float32Array[chunkSize]` | Вещественный сигнал |
| `complex` | `Float32Array[chunkSize × 2]` | Комплексный (I/Q чередование) |
| `null` | — | Нет входа (генераторы) или выхода (визуализация) |

## Общая структура плагина

```javascript
{
    type: 'Название на русском',     // отображается в UI
    id: 'kebab-case-id',             // уникальный идентификатор
    icon: 'dsp-icon-name',           // SVG-иконка из DspIcons
    description: 'Подсказка',        // tooltip
    group: 'group-id',               // категория в тулбаре
    signals: {
        input: 'real' | 'complex' | null,
        output: 'real' | 'complex' | null,
        inputsCount: 1,              // кол-во входов (опционально)
        outputsCount: 1,             // кол-во выходов (опционально)
    },
    defaultParams: { ... },
    processor: {
        states: new Map(),           // состояние по nodeId
        clearStates() { ... },
        process(inputs, params, chunkSize, nodeId) { ... }
    }
}
```

## Обработка

- Размер чанка: **1024 сэмпла**
- Формат данных: **Float32Array**
- Частота дискретизации по умолчанию: **48000 Гц** (передаётся через `params.sampleRate`)
