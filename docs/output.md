# Вывод

Блоки для вывода обработанного сигнала.

[← К оглавлению](index.md)

---

## Динамик

| | |
|---|---|
| **ID** | `speaker` |
| **Иконка** | `dsp-speaker` |
| **Вход → Выход** | real → — |

Воспроизведение сигнала через Web Audio API.

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `muted` | false | Отключение звука |

### Алгоритм

Конечный узел графа — передаёт входной буфер на аудиовыход. При `muted = true` возвращает нулевой буфер.
