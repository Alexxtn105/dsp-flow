# Визуализация

Блоки для отображения сигналов. Не имеют выходов — являются конечными узлами графа.

## Осциллограф

| | |
|---|---|
| **ID** | `oscilloscope` |
| **Иконка** | `dsp-oscilloscope` |
| **Вход → Выход** | real (×4) → — |

## Спектроанализатор

| | |
|---|---|
| **ID** | `spectrum-analyzer` |
| **Иконка** | `dsp-spectrum` |
| **Вход → Выход** | real → — |

Анализ спектра сигнала с оконными функциями и экспоненциальным усреднением.

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `fftSize` | 2048 | Размер БПФ |
| `windowFunction` | `'blackman-harris'` | Оконная функция |
| `dBScale` | true | Шкала в дБ |
| `averaging` | 5 | Кол-во кадров усреднения |

### Алгоритм

БПФ с перекрытием блоков. Экспоненциальное усреднение: `avg += (1/N)·(current - avg)`. Логарифмическая шкала: `20·log₁₀(magnitude)`.
