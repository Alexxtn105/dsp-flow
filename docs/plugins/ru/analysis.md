# Анализ

Блоки спектрального и корреляционного анализа сигналов.

---

## Спектроанализатор (Spectrum Analyzer)

**ID:** `spectrum-analyzer` | **Группа:** visualization | **Вход:** real | **Выход:** null (визуализация)

### Назначение

Показывает частотный состав входного сигнала в реальном времени. Раскладывает сигнал на частотные составляющие и отображает их в виде графика «амплитуда от частоты». Основной инструмент диагностики в ЦОС: позволяет увидеть полезный сигнал, шум, гармоники, помехи и оценить эффективность фильтрации.

### Алгоритм

1. Входные отсчёты записываются в кольцевой буфер размером fftSize.
2. Содержимое буфера умножается на оконную функцию (Blackman-Harris по умолчанию) для уменьшения «утечки» спектра.
3. Выполняется быстрое преобразование Фурье (БПФ/FFT).
4. Из комплексных коэффициентов вычисляется магнитуда в дБ или линейном масштабе.
5. Применяется экспоненциальное усреднение: S[n] = S[n-1] + α*(X[n] - S[n-1]), где α = 1/averaging.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| fftSize | int | 2048 | Размер БПФ. Частотное разрешение: Δf = sampleRate / fftSize. Степень двойки: 512, 1024, 2048, 4096, 8192. |
| windowFunction | string | 'blackman-harris' | Оконная функция: 'hann', 'hamming', 'blackman', 'blackman-harris', 'rectangular'. |
| dBScale | boolean | true | Отображение в децибелах. |
| averaging | int | 5 | Кадров экспоненциального усреднения. 1 = без усреднения, 5–10 = сглаженный спектр. |

### Примеры использования

1. **Анализ тонального сигнала:**
   `Sine(1000 Гц) → SpectrumAnalyzer` — острый пик на 1 кГц.

2. **Оценка фильтрации:**
   `NoiseGenerator → LowpassFIR(cutoff=2000) → SpectrumAnalyzer` — спектр обрезан выше 2 кГц.

3. **Поиск гармоник:**
   `AudioFile → SpectrumAnalyzer(fftSize=4096, averaging=10)` — увеличенный размер БПФ для тонкой структуры спектра.

## Коррелятор (Correlator)

**ID:** `correlator` | **Группа:** real-math | **Вход:** 2x real | **Выход:** real

### Назначение

Взаимная корреляция (cross-correlation) — мера сходства двух сигналов как функция временного сдвига (лага). Пик корреляционной функции указывает на лаг максимального совпадения. Применяется для оценки временной задержки, обнаружения сигнала в шуме (matched filter) и измерения сходства.

### Алгоритм

Быстрый метод через БПФ: R(τ) = IFFT(FFT(x1) * conj(FFT(x2))), сложность O(N*log N). Шаги:
1. Нормализация: вычитание средних, расчёт энергий.
2. Zero-padding до степени двойки для линейной (не циклической) корреляции.
3. FFT(x1) * conj(FFT(x2)) → IFFT.
4. Нормализация: деление на sqrt(E1 * E2).
5. Выход центрирован: лаг 0 в середине массива.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| normalize | boolean | true | Нормализация. При включении: выход в диапазоне [-1, +1]. |
| maxLag | int | 0 | Максимальный лаг. 0 = полный диапазон. |

### Примеры использования

1. **Измерение задержки:**
   `Sine(1000) → Коррелятор (Вход 1)`, `Sine(1000) → DelayLine(50) → Коррелятор (Вход 2) → Oscilloscope` — пик смещён на 50 отсчётов вправо от центра.

2. **Обнаружение сигнала в шуме:**
   `[Sine(1000) + NoiseGenerator(уровень=2)] → Коррелятор (Вход 1)`, `Sine(1000) → Коррелятор (Вход 2)` — корреляция с эталоном даёт выраженный пик даже при сильном шуме.

3. **Сравнение разных сигналов:**
   `Sine(1000) → Коррелятор (Вход 1)`, `Sine(2000) → Коррелятор (Вход 2)` — нормализованная корреляция близка к 0.
