# Генераторы

Блоки-источники сигналов. Генераторы не имеют обязательных входов (кроме управляемых NCO) и формируют сигналы для дальнейшей обработки в графе.

---

## Синусный генератор (Sine Generator)

**ID:** `sine-generator` | **Группа:** generators | **Вход:** нет | **Выход:** real

### Назначение

Генерирует непрерывный синусоидальный сигнал вида s(t) = A * sin(2π*f*t + φ). Это самый базовый блок в цифровой обработке сигналов, используемый как тестовый сигнал, несущая частота, опорный тон и строительный кирпичик для сложных сигналов.

### Алгоритм

Используется фазовый аккумулятор (phase accumulator) — на каждом отсчёте фаза увеличивается на Δφ = 2π*f / sampleRate. Значение синуса вычисляется как Math.sin(currentPhase + phaseOffset). Фаза нормализуется в диапазоне [0, 2π) для предотвращения потери точности при длительной работе. Аккумулятор сохраняет состояние между чанками, обеспечивая непрерывность сигнала без щелчков и разрывов.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| frequency | float | 1000 | Частота синусоиды в Гц. Диапазон: 0 до sampleRate/2. Типичные значения: 440 (нота «ля»), 1000 (тестовый тон), 10000 (несущая). |
| amplitude | float | 1.0 | Амплитуда сигнала. Диапазон: 0.0–1.0. Значения > 1.0 допустимы, но могут вызвать клиппинг при воспроизведении через Speaker. |
| phase | float | 0 | Начальное смещение фазы в градусах. Диапазон: 0–360°. Преобразуется в радианы: phaseOffset = phase * π/180. |

### Примеры использования

1. **Простое наблюдение синусоиды:**
   `Sine(1000 Гц) → Oscilloscope` — на осциллографе видна чистая синусоида с частотой 1 кГц.

2. **Спектральный анализ суммы тонов:**
   `Sine(1000 Гц) + Sine(3000 Гц) → Summer → SpectrumAnalyzer` — на спектре видны два пика: на 1 кГц и 3 кГц.

3. **Модуляция несущей:**
   `Sine(100 Гц, амплитуда 0.5) → AMFMPMModulator(FM, несущая 10000 Гц)` — синусоида 100 Гц используется как модулирующий сигнал для FM-модуляции.

4. **Тестирование фильтра:**
   `Sine(5000 Гц) → LowpassFIR(cutoff 3000 Гц) → Oscilloscope` — сигнал 5 кГц подавляется фильтром — на выходе почти тишина.

## Косинусный генератор (Cosine Generator)

**ID:** `cosine-generator` | **Группа:** generators | **Вход:** нет | **Выход:** real

### Назначение

Генерирует непрерывный косинусоидальный сигнал вида s(t) = A * cos(2π*f*t + φ). Косинус — это тот же синус, но сдвинутый на 90° (π/2 радиан) вперёд по фазе. Такой сигнал необходим для формирования квадратурных пар (I/Q), где синус представляет квадратурную (Q) компоненту, а косинус — синфазную (I).

### Алгоритм

Идентичен синусному генератору, но вместо Math.sin используется Math.cos. Фазовый аккумулятор увеличивается на Δφ = 2π*f / sampleRate каждый отсчёт. Состояние аккумулятора сохраняется между чанками для непрерывности сигнала. Фаза нормализуется в [0, 2π) для предотвращения потери точности float.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| frequency | float | 1000 | Частота косинусоиды в Гц. Диапазон: 0 до sampleRate/2. |
| amplitude | float | 1.0 | Амплитуда сигнала. Диапазон: 0.0–1.0 (значения > 1.0 допустимы, но могут вызвать клиппинг). |
| phase | float | 0 | Начальное смещение фазы в градусах. Диапазон: 0–360°. |

### Примеры использования

1. **Формирование квадратурной пары (ручное):**
   `Sine(1000 Гц) → Multiplier (Q-ветка)`, `Cosine(1000 Гц) → Multiplier (I-ветка)` — два сигнала одной частоты, но со сдвигом 90°, образуют I/Q-пару.

2. **Проверка ортогональности:**
   `Sine(1000 Гц) → Multiplier ← Cosine(1000 Гц) → Integrator` — интеграл произведения sin*cos за целое число периодов стремится к нулю.

3. **Когерентная демодуляция AM:**
   `AMFMPMModulator(AM, несущая 10000 Гц) → Multiplier ← Cosine(10000 Гц) → LowpassFIR → Oscilloscope` — косинус той же частоты используется для синхронного детектирования.

## Референсный синусный генератор (Reference Sine Generator / NCO)

**ID:** `ref-sine-generator` | **Группа:** generators | **Вход:** 2x real | **Выход:** complex

### Назначение

NCO (Numerically Controlled Oscillator) — генератор с внешним управлением частотой и фазой. В отличие от обычного синусного генератора, частота и фаза могут изменяться в реальном времени через управляющие входы. Это ключевой блок для построения PLL (петля фазовой автоподстройки), когерентных демодуляторов, адаптивных фильтров и систем частотного синтеза.

### Алгоритм

Фазовый аккумулятор аналогичен обычному генератору, но на каждом отсчёте:
1. Мгновенная частота берётся из входа управления (или из параметра frequency).
2. Смещение фазы берётся из второго входа (или из параметра phase).
3. Вычисляется приращение: Δφ = 2π * freq / sampleRate.
4. Формируется комплексный выход: I = sin(phase), Q = cos(phase).

NCO выдаёт аналитический сигнал — комплексную экспоненту e^(jφ), представленную парой I/Q. Формат выхода: interleaved [I0, Q0, I1, Q1, ...].

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| frequency | float | 1000 | Базовая частота в Гц. Используется, когда вход частоты не подключён. |
| amplitude | float | 1.0 | Амплитуда выходного сигнала. Диапазон: 0.0–1.0. |
| phase | float | 0 | Базовое смещение фазы в градусах. Используется, когда вход фазы не подключён. |
| controllable | bool | true | Флаг управляемого генератора. |

**Входы:**
- Вход 0 «Частота (Гц)» — мгновенная частота, Гц.
- Вход 1 «Фаза (рад)» — мгновенное смещение фазы, радианы.

### Примеры использования

1. **PLL — петля фазовой автоподстройки:**
   `PSKModulator(QPSK) → PhaseDetector → LoopFilter → RefSine(вход частоты) → PhaseDetector (опорный вход)` — NCO генерирует опорный сигнал, частота которого подстраивается петлевым фильтром.

2. **Управляемый гетеродин (сдвиг частоты):**
   `Constant(5000) → RefSine(вход частоты) → ComplexMultiplier ← входной сигнал` — NCO на фиксированной частоте 5 кГц используется для переноса спектра.

3. **Частотная модуляция через NCO:**
   `Sine(100 Гц) → Gain(1000) → RefSine(вход частоты) → Oscilloscope` — модулирующий сигнал 100 Гц управляет частотой NCO, создавая FM-сигнал.

## Референсный косинусный генератор (Reference Cosine Generator / NCO)

**ID:** `ref-cosine-generator` | **Группа:** generators | **Вход:** 2x real | **Выход:** complex

### Назначение

NCO с косинусной квадратурой. Аналогичен RefSine, но формирует комплексный выход с другим отображением I/Q: I = cos(φ), Q = −sin(φ). Это соответствует комплексной экспоненте e^(−jφ), что удобно для задач, где требуется сопряжённый опорный сигнал (например, понижающее преобразование частоты = умножение на e^(−j*2π*f*t)).

### Алгоритм

Фазовый аккумулятор идентичен RefSine. На каждом отсчёте формируется комплексный выход: I = cos(phase), Q = −sin(phase). Фаза нормализуется в [0, 2π).

**Отличие от RefSine:**
- RefSine: I = sin(φ), Q = cos(φ) — представляет e^(jφ)
- RefCosine: I = cos(φ), Q = −sin(φ) — представляет e^(−jφ)

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| frequency | float | 1000 | Базовая частота в Гц. |
| amplitude | float | 1.0 | Амплитуда выходного сигнала. |
| phase | float | 0 | Базовое смещение фазы в градусах. |
| controllable | bool | true | Флаг управляемого генератора. |

**Входы:**
- Вход 0 «Частота (Гц)» — мгновенная частота, Гц.
- Вход 1 «Фаза (рад)» — мгновенное смещение фазы, радианы.

### Примеры использования

1. **Понижающее преобразование частоты (downconversion):**
   `Входной сигнал на несущей 10 кГц → ComplexMultiplier ← RefCosine(10000 Гц) → LowpassFIR → Constellation` — умножение на e^(−j*2π*10000*t) переносит спектр на нулевую частоту (baseband).

2. **PLL с косинусным NCO:**
   `Сигнал → PhaseDetector → LoopFilter → RefCosine(вход частоты) → PhaseDetector (опорный)` — используется, когда фазовый детектор ожидает косинусный опорный сигнал.

## Audio File (Источник аудиосигнала)

**ID:** `audio-file` | **Группа:** generators | **Вход:** нет | **Выход:** real

### Назначение

Позволяет загрузить WAV-файл и использовать его как источник реального сигнала в графе обработки. Это необходимо для работы с реальными записями: анализ речи, музыки, радиосигналов, тестирование фильтров и детекторов на реальных данных вместо синтетических генераторов.

### Алгоритм

Данный плагин является «заглушкой» (placeholder). Фактическое чтение WAV-файла и подача аудиоданных в граф выполняется в DSPProcessor. Поддерживаемый формат: WAV (PCM). Стерео файлы микшируются в моно. Частота дискретизации приводится к sampleRate симуляции.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| wavFile | File / null | null | Объект File, выбранный пользователем через диалог загрузки. null = файл не загружен. |

### Примеры использования

1. **Анализ спектра аудиозаписи:**
   `AudioFile(speech.wav) → SpectrumAnalyzer` — загруженная запись речи отображается на спектроанализаторе.

2. **Фильтрация аудиосигнала:**
   `AudioFile(music.wav) → BandpassFIR(200–3400 Гц) → Speaker` — музыка фильтруется полосовым фильтром (телефонная полоса) и воспроизводится.

3. **Водопадная диаграмма:**
   `AudioFile(radio.wav) → Waterfall` — визуализация изменения спектра радиосигнала во времени.

## Константа (Constant)

**ID:** `constant` | **Группа:** generators | **Вход:** нет | **Выход:** real

### Назначение

Генерирует сигнал с постоянным значением на каждом отсчёте. Применяется как DC-смещение (bias), управляющий сигнал (фиксированное значение частоты для NCO), масштабирующий коэффициент (через Multiplier), пороговый уровень (для блока Threshold) и тестовый сигнал.

### Алгоритм

Тривиальный: выходной массив Float32Array заполняется одним и тем же значением через метод fill(). Никаких состояний между чанками не хранится.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| value | float | 1.0 | Значение константы. Допустим любой float: положительные, отрицательные, нулевые значения. |

### Примеры использования

1. **Задание частоты для NCO:**
   `Constant(5000) → RefSine(вход частоты)` — NCO будет генерировать сигнал на фиксированной частоте 5 кГц.

2. **DC-смещение сигнала:**
   `Sine(1000 Гц) + Constant(0.5) → Summer → Oscilloscope` — синусоида смещается вверх на 0.5.

3. **Масштабирование (ручной Gain):**
   `Входной сигнал → Multiplier ← Constant(0.1)` — сигнал ослабляется в 10 раз.

## Генератор шума (Noise Generator)

**ID:** `noise-generator` | **Группа:** generators | **Вход:** нет | **Выход:** real

### Назначение

Генерирует псевдослучайный шумовой сигнал трёх типов, каждый из которых имеет свою спектральную характеристику. Шум используется для тестирования фильтров, моделирования каналов связи с аддитивным шумом, генерации dithering-сигнала.

### Алгоритм

- **white (белый шум)** — плоский спектр, равномерная мощность на всех частотах. Генерируется как `Math.random() * 2 - 1`.
- **pink (розовый шум, 1/f)** — мощность убывает обратно пропорционально частоте (−3 дБ/октава). Реализация: фильтр Paul Kellet — каскад из 7 IIR-фильтров первого порядка. Выход нормализуется коэффициентом 0.11.
- **brown (красный/броуновский шум, 1/f^2)** — мощность убывает как 1/f^2 (−6 дБ/октава). Реализация: интеграция белого шума с ограничением.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| noiseType | string | 'white' | Тип шума: 'white', 'pink', 'brown'. |
| amplitude | float | 1.0 | Амплитуда (множитель). Диапазон: 0.0–1.0. |

### Примеры использования

1. **Визуализация АЧХ фильтра:**
   `NoiseGenerator(white) → LowpassFIR(cutoff 5000 Гц) → SpectrumAnalyzer` — белый шум проходит через фильтр. На спектроанализаторе видна АЧХ фильтра.

2. **Моделирование шумового канала:**
   `Sine(1000 Гц) + NoiseGenerator(white, амплитуда 0.1) → Summer → Oscilloscope` — синусоида с добавленным белым шумом.

3. **Сравнение спектров шума:**
   `NoiseGenerator(white) → SpectrumAnalyzer` (плоский спектр), `NoiseGenerator(pink) → SpectrumAnalyzer` (спад 3 дБ/октава), `NoiseGenerator(brown) → SpectrumAnalyzer` (спад 6 дБ/октава).

## АМ/ЧМ/ФМ модулятор (AM/FM/PM Modulator)

**ID:** `amfmpm-modulator` | **Группа:** generators | **Вход:** real | **Выход:** real

### Назначение

Принимает модулирующий (информационный) сигнал и переносит его на высокочастотную несущую одним из трёх способов: амплитудная (AM), частотная (FM) или фазовая (PM) модуляция. Это базовые виды аналоговой модуляции, используемые в радиосвязи, радиовещании и телеметрии.

### Алгоритм

Используется фазовый аккумулятор с базовым приращением Δφ = 2π * fc / sampleRate.

- **AM:** s(t) = (1 + m * x(t)) * cos(φ). Амплитуда несущей изменяется пропорционально модулирующему сигналу. Спектр: несущая + две боковые полосы (fc ± fm).
- **FM:** s(t) = cos(φ), где φ += Δφ + 2π * m * x(t) / sampleRate. Мгновенная частота отклоняется от несущей. Параметр m — частотная девиация (Гц). Ширина спектра ≈ 2*(Δf + fm) (правило Карсона).
- **PM:** s(t) = cos(φ + m * x(t)). Фаза несущей сдвигается пропорционально x(t). Параметр m — индекс фазовой модуляции (радианы).

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| modulationType | string | 'AM' | Тип модуляции: 'AM', 'FM', 'PM'. |
| carrierFrequency | float | 10000 | Частота несущей в Гц. Должна быть значительно выше частоты модулирующего сигнала. |
| modulationIndex | float | 0.5 | Индекс/глубина модуляции. Для AM: 0–1 (глубина). Для FM: девиация в Гц. Для PM: индекс в радианах. |

### Примеры использования

1. **AM-модуляция с наблюдением огибающей:**
   `Sine(500 Гц) → AMFMPMModulator(AM, несущая 10000, m=0.8) → Oscilloscope` — видна высокочастотная несущая с огибающей в форме синуса.

2. **FM-модуляция и спектральный анализ:**
   `Sine(200 Гц) → AMFMPMModulator(FM, несущая 5000, девиация 1000) → SpectrumAnalyzer` — видна несущая с боковыми полосами.

3. **FM-демодуляция:**
   `Sine(100 Гц) → AMFMPMModulator(FM, 8000, девиация 500) → FrequencyDiscriminator → LowpassFIR → Oscilloscope` — частотный дискриминатор извлекает модулирующий сигнал.

## PSK модулятор (PSK Modulator)

**ID:** `psk-modulator` | **Группа:** generators | **Вход:** нет | **Выход:** complex

### Назначение

Генерирует модулированный сигнал с фазовой манипуляцией (Phase Shift Keying). PSK — основной вид цифровой модуляции, где информация кодируется в фазе несущей. Каждому символу соответствует определённая точка на фазовой диаграмме (созвездии). Блок генерирует псевдослучайные данные через PRBS и формирует I/Q-отсчёты.

### Алгоритм

1. Вычисляется samplesPerSymbol = sampleRate / symbolRate.
2. Когда счётчик отсчётов достигает samplesPerSymbol, генерируется новый символ через LFSR (полином 0x80000057, seed 0x1234ABCD).
3. Из 1/2/3 бит формируется точка созвездия (I, Q).

**Схемы созвездия:**
- **BPSK** — 2 точки (1 бит/символ). Фазы: 0° и 180°.
- **QPSK** — 4 точки (2 бита/символ). Фазы: 45°, 135°, 225°, 315°.
- **8PSK** — 8 точек (3 бита/символ). Фазы: 0°, 45°, 90°, ..., 315°.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| constellation | string | 'QPSK' | Схема созвездия: 'BPSK', 'QPSK', '8PSK'. |
| symbolRate | float | 1000 | Символьная скорость в символах/с (бод). Диапазон: 10–sampleRate/4. |
| amplitude | float | 1.0 | Амплитуда точек созвездия. Диапазон: 0.0–1.0. |

### Примеры использования

1. **Наблюдение QPSK-созвездия:**
   `PSKModulator(QPSK, symbolRate 1000) → Constellation` — на диаграмме видны 4 точки в углах квадрата.

2. **Полная цепочка демодуляции QPSK:**
   `PSKModulator(QPSK, sps=4) → канал с шумом → TimingRecovery(sps=4) → PLL → Constellation` — символьная синхронизация и PLL компенсируют сдвиги.

3. **Спектр PSK-сигнала:**
   `PSKModulator(BPSK, symbolRate 500) → SpectrumAnalyzer` — спектр имеет форму sinc^2 с основным лепестком шириной 2 * symbolRate.
