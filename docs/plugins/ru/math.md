# Математические блоки

Арифметические и нелинейные операции над действительными и комплексными сигналами.

---

## Сумматор (Summer)

**ID:** `summer` | **Группа:** math-blocks | **Вход:** 2x real | **Выход:** real

### Назначение

Складывает два (или более) действительных сигнала с заданными весовыми коэффициентами. Базовый блок для смешивания сигналов и формирования суммарных/разностных каналов.

### Алгоритм

y[n] = w0*x0[n] + w1*x1[n] + ... Нормализация: усреднение (деление на число входов) или пиковая (деление на максимум).

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| numInputs | int | 2 | Количество входов. |
| weights | float[] | [1.0, 1.0] | Весовые коэффициенты. Отрицательный вес — вычитание. |
| normalization | string | 'none' | 'none', 'average' (среднее) или 'peak' (нормализация по пику). |

### Примеры использования

1. **Смешивание тонов:** `Sine(1000) + Sine(3000) → Summer → Oscilloscope`.
2. **Вычитание:** `Summer(weights: [1.0, -1.0])` — вычитает второй вход из первого.
3. **Усреднение:** `Summer(normalization: 'average')` — среднее для снижения шума.

## Перемножитель (Multiplier)

**ID:** `multiplier` | **Группа:** math-blocks | **Вход:** 2x real | **Выход:** real

### Назначение

Перемножает (или делит) два действительных сигнала поэлементно. Основа амплитудной модуляции, балансного смешивания и синхронного детектирования.

### Алгоритм

Умножение: y[n] = x0[n] * x1[n] * scaleFactor. Деление: y[n] = x0[n] / x1[n] * scaleFactor (защита от деления на ноль).

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| numInputs | int | 2 | Количество входов. |
| operation | string | 'multiply' | 'multiply' или 'divide'. |
| scaleFactor | float | 1.0 | Масштабный коэффициент. |

### Примеры использования

1. **Амплитудная модуляция:** `Sine(1000) * Sine(100) → Multiplier → SpectrumAnalyzer` — боковые полосы на 900 и 1100 Гц.
2. **Синхронное детектирование:** `АМ-сигнал * Sine(несущая) → Multiplier → LowpassFIR → Oscilloscope`.

## Интегратор (Integrator)

**ID:** `integrator` | **Группа:** math-blocks | **Вход:** real | **Выход:** real

### Назначение

Вычисляет накопительную сумму (интеграл) входного сигнала по времени. Используется для преобразования частоты в фазу (NCO), вычисления среднего и в ПИД-регуляторах.

### Алгоритм

Метод трапеций: y[n] = y[n-1] + (x[n] + x[n-1]) * dt / 2. При переполнении — сброс или насыщение.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| resetOnOverflow | bool | true | true — сброс в 0 (пилообразный выход); false — насыщение на ±maxValue. |
| maxValue | float | 1000 | Порог переполнения. |

### Примеры использования

1. **Пилообразный сигнал:** `Constant(100) → Integrator → Oscilloscope` — линейное нарастание.
2. **Сглаживание:** `Шумовой сигнал → Integrator(maxValue: 10) → Oscilloscope` — подавление ВЧ шума.

## Re (действительная часть / Real Part)

**ID:** `real-part` | **Группа:** math-blocks | **Вход:** complex | **Выход:** real

### Назначение

Извлекает действительную (синфазную, I) компоненту комплексного сигнала: output[n] = input[2n].

### Параметры

Нет параметров.

### Примеры использования

1. **Визуализация I-компоненты:** `RefSine(1000) → RealPart → Oscilloscope`.
2. **Переход к действительному сигналу:** `Комплексный фильтр → RealPart → Speaker`.

## Im (мнимая часть / Imaginary Part)

**ID:** `imag-part` | **Группа:** math-blocks | **Вход:** complex | **Выход:** real

### Назначение

Извлекает мнимую (квадратурную, Q) компоненту комплексного сигнала: output[n] = input[2n + 1].

### Параметры

Нет параметров.

### Примеры использования

1. **Визуализация Q-компоненты:** `RefSine(1000) → ImagPart → Oscilloscope`.
2. **Проверка баланса I/Q:** сравнение амплитуд RealPart и ImagPart.

## Комплексный перемножитель (Complex Multiplier)

**ID:** `complex-multiplier` | **Группа:** math-blocks | **Вход:** 2x complex | **Выход:** complex

### Назначение

Перемножает два комплексных сигнала: z1*z2 складывает фазы и перемножает амплитуды. Фундаментальная операция для частотного преобразования и фазового вращения.

### Алгоритм

(a + jb) * (c + jd) = (ac - bd) + j(ad + bc)

### Параметры

Нет параметров.

### Примеры использования

1. **Перенос спектра:** `Сигнал * NCO(RefSine) → ComplexMultiplier → SpectrumAnalyzer`.
2. **Фазовое вращение:** `Сигнал * exp(jφ) → ComplexMultiplier`.

### Назначение

### Параметры

### Примеры использования

1. **Сложение комплексных сигналов:** `RefSine(1000) + RefSine(3000) → ComplexSummer → SpectrumAnalyzer`.

## Комплексный квадрат (Complex Square)

**ID:** `complex-square` | **Группа:** math-blocks | **Вход:** complex | **Выход:** complex

### Назначение

z^2 = (Re + jIm)^2. Удваивает фазовые углы. Для BPSK «схлопывает» обе точки в одну, позволяя восстановить несущую.

### Алгоритм

Re_out = Re^2 - Im^2, Im_out = 2*Re*Im. В полярных: |z^2| = |z|^2, arg(z^2) = 2*arg(z).

### Параметры

Нет параметров.

### Примеры использования

1. **Восстановление несущей BPSK:** `BPSK → ComplexSquare → BandpassFIR(2*fc) → SpectrumAnalyzer`.
2. **Снятие QPSK-неоднозначности:** `QPSK → ComplexSquare → Constellation` — 4 точки → 2 точки.

---

## Комплексный корень (Complex Sqrt)

**ID:** `complex-sqrt` | **Группа:** math-blocks | **Вход:** complex | **Выход:** complex

### Назначение

√z = √|z| * exp(jθ/2). Делит фазовые углы пополам — обратная операция к ComplexSquare.

### Алгоритм

r = sqrt(Re^2 + Im^2), θ = atan2(Im, Re), Re_out = √r * cos(θ/2), Im_out = √r * sin(θ/2).

### Параметры

Нет параметров.

### Примеры использования

1. **Деление частоты:** `ComplexSquare → ComplexSqrt → Constellation`.
2. **Восстановление несущей:** `BPSK → ComplexSquare → PLL(2*fc) → ComplexSqrt`.

---

## Фаза (комплексная) (Complex Phase)

**ID:** `complex-phase` | **Группа:** math-blocks | **Вход:** complex | **Выход:** real

### Назначение

Извлекает мгновенную фазу: arg(z) = atan2(Im, Re). Результат в радианах от -π до +π.

### Параметры

Нет параметров.

### Примеры использования

1. **Пилообразная фаза:** `RefSine(1000) → ComplexPhase → Oscilloscope`.
2. **Фазовая демодуляция PSK:** `PSK → PLL → ComplexPhase → Oscilloscope` — дискретные значения фазы.

## Амплитуда (комплексная) (Complex Magnitude)

**ID:** `complex-magnitude` | **Группа:** math-blocks | **Вход:** complex | **Выход:** real

### Назначение

|z| = sqrt(Re^2 + Im^2). Извлекает амплитуду комплексного сигнала. Применяется для AM-демодуляции и измерения уровня.

### Параметры

Нет параметров.

### Примеры использования

1. **Проверка эталонного сигнала:** `RefSine(1000) → ComplexMagnitude → Oscilloscope` — |z| = 1.0 = const.
2. **AM-демодуляция:** `АМ-сигнал (I/Q) → ComplexMagnitude → Oscilloscope`.

## Формирователь комплексного (Complex Composer)

**ID:** `complex-composer` | **Группа:** math-blocks | **Вход:** 2x real | **Выход:** complex

### Назначение

Объединяет два действительных сигнала в один комплексный: первый вход → Re, второй → Im. Обратная операция к RealPart/ImagPart.

### Параметры

Нет параметров.

**Входы:**
- Верхний вход: Re (действительная часть)
- Нижний вход: Im (мнимая часть)

### Примеры использования

1. **Квадратурный сигнал:** `Sine(1000) + Cosine(1000) → ComplexComposer → Constellation` — окружность.
2. **Восстановление после раздельной обработки:** `RealPart → Фильтр → [Re]`, `ImagPart → Фильтр → [Im] → ComplexComposer`.

## Комплексное сопряжение (Complex Conjugate)

**ID:** `complex-conjugate` | **Группа:** math-blocks | **Вход:** complex | **Выход:** complex

### Назначение

a+jb → a−jb. Инвертирует мнимую часть. Используется в корреляции (x*conj(y)), согласованной фильтрации и обращении частоты вращения.

### Параметры

Нет параметров.

### Примеры использования

1. **Корреляция:** `Сигнал_B → ComplexConjugate → ComplexMultiplier (*Сигнал_A)`.
2. **Обращение спектра:** `Сигнал → ComplexConjugate → SpectrumAnalyzer` — обращает знак частоты.

## Квадрат (действительный) (Real Square)

**ID:** `real-square` | **Группа:** math-blocks | **Вход:** real | **Выход:** real

### Назначение

y[n] = x[n]^2. Удвоение частоты и детектирование мощности. Для cos(2πft): cos^2 = (1 + cos(2*2πft))/2.

### Параметры

Нет параметров.

### Примеры использования

1. **Удвоение частоты:** `Sine(1000) → RealSquare → SpectrumAnalyzer` — пик на 2000 Гц.
2. **Оценка мощности:** `Сигнал → RealSquare → LowpassFIR → NumericIndicator`.

## Степень 4 (действительная) (Real Power 4)

**ID:** `real-power4` | **Группа:** math-blocks | **Вход:** real | **Выход:** real

### Назначение

y[n] = x[n]^4. Для QPSK (M=4) возведение в 4-ю степень устраняет модуляцию, и на частоте 4*fc появляется спектральная линия.

### Алгоритм

y[n] = (x[n]^2)^2 — два последовательных умножения.

### Параметры

Нет параметров.

### Примеры использования

1. **Восстановление несущей QPSK:** `QPSK → RealPower4 → SpectrumAnalyzer` — пик на 4*fc.
2. **Анализ модуляции:** пик на 4*f → QPSK, на 2*f → BPSK, на 8*f → 8-PSK.

## Арктангенс (Atan2)

**ID:** `atan2` | **Группа:** math-blocks | **Вход:** 2x real | **Выход:** real

### Назначение

atan2(Y, X) — угол в радианах [-π, π] по двум компонентам. Корректно определяет квадрант.

### Параметры

Нет параметров.

**Входы:**
- Верхний вход: Y (вертикальная/мнимая компонента)
- Нижний вход: X (горизонтальная/действительная компонента)

### Примеры использования

1. **Фаза из I/Q:** `RealPart → [X], ImagPart → [Y] → Atan2 → Oscilloscope` — эквивалент ComplexPhase.
2. **Детектирование направления:** `Sine → [Y], Cosine → [X] → Atan2 → Oscilloscope` — пилообразный сигнал.

## АРУ (AGC — Automatic Gain Control)

**ID:** `agc` | **Группа:** math-blocks | **Вход:** real | **Выход:** real

### Назначение

Поддерживает постоянный уровень выходного сигнала независимо от изменений входного. Применяется в радиоприёмниках, аудиосистемах и телекоммуникациях.

### Алгоритм

1. Огибающая: env += coeff * (|x[n]| - env) (attack/release).
2. Усиление: gain = min(targetLevel / env, maxGain).
3. Выход: y[n] = x[n] * gain.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| targetLevel | float | 1.0 | Целевой уровень. Диапазон: 0.01–10. |
| attackTime | float | 5 | Время атаки, мс. Диапазон: 0.1–100. |
| releaseTime | float | 50 | Время восстановления, мс. Диапазон: 1–1000. |
| maxGain | float | 100 | Максимальное усиление. Диапазон: 1–10000. |

### Примеры использования

1. **Нормализация громкости:** `AudioFile → AGC(target: 1.0) → Oscilloscope` — тихие участки усиливаются, громкие ослабляются.
2. **Стабилизация в приёмнике:** `Антенна → Фильтр → AGC(target: 0.5, maxGain: 1000) → Демодулятор`.

## Усилитель (Gain)

**ID:** `gain` | **Группа:** math-blocks | **Вход:** real | **Выход:** real

### Назначение

Умножает сигнал на постоянный коэффициент. Согласование уровней, аттенюация, инверсия фазы.

### Алгоритм

Линейный: y[n] = x[n] * gain * (invert ? -1 : 1). В дБ: linearGain = 10^(gaindB / 20).

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| gain | float | 1.0 | Коэффициент усиления. В linear: 0 = тишина, 1.0 = без изменения, 2.0 = удвоение. В дБ: 0 = без изменения, +20 = 10x. |
| gainMode | string | 'linear' | 'linear' или 'dB'. |
| invert | bool | false | Инверсия фазы (умножение на -1). |

### Примеры использования

1. **Ослабление на 6 дБ:** `Sine(1000) → Gain(-6 дБ, mode: dB) → Oscilloscope`.
2. **Инверсия фазы:** `Sine → Gain(invert: true) → Summer (с оригиналом)` — получается ноль.

## Логарифм/Экспонента (Log/Exp)

**ID:** `log-exp` | **Группа:** math-blocks | **Вход:** real | **Выход:** real

### Назначение

Применяет одну из пяти математических функций: ln, log10, dB, exp, pow10.

### Алгоритм

- `ln`: y = ln(max(|x|, ε))
- `log10`: y = log10(max(|x|, ε))
- `dB`: y = 20*log10(max(|x|, ε))
- `exp`: y = e^(min(x, 88))
- `pow10`: y = 10^(min(x, 38))

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| function | string | 'ln' | Функция: 'ln', 'log10', 'dB', 'exp', 'pow10'. |
| epsilon | float | 1e-10 | Минимальное значение аргумента логарифма. |

### Примеры использования

1. **Уровень в дБ:** `Сигнал → LogExp(function: 'dB') → NumericIndicator`.
2. **Сжатие диапазона:** `AudioFile → LogExp(function: 'log10') → Oscilloscope`.

## Смеситель (Mixer)

**ID:** `mixer` | **Группа:** math-blocks | **Вход:** real | **Выход:** complex

### Назначение

Умножает входной сигнал на комплексную экспоненту exp(j*2π*f*t), выполняя перенос (сдвиг) спектра. Ключевая операция в SDR и супергетеродинных приёмниках.

### Алгоритм

I[n] = x[n] * cos(φ[n]), Q[n] = x[n] * sin(φ[n]), φ[n] = φ[n-1] + 2π * fShift / sampleRate.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| shiftFrequency | float | 1000 | Частота сдвига, Гц. Положительные — вверх, отрицательные — вниз. |

### Примеры использования

1. **Перенос спектра вверх:** `Sine(500) → Mixer(1000) → SpectrumAnalyzer` — пик на 1500 Гц.
2. **Частотное преобразование в приёмнике:** `Сигнал → Mixer(-fc) → LowpassFIR → Демодулятор`.

## Компаратор (Threshold)

**ID:** `threshold` | **Группа:** math-blocks | **Вход:** real | **Выход:** real

### Назначение

Сравнивает сигнал с порогом и формирует двухуровневый сигнал. Аналог компаратора напряжения / триггера Шмитта (с гистерезисом).

### Алгоритм

Без гистерезиса: y = x > threshold ? high : low. С гистерезисом: верхний порог = threshold + hysteresis/2, нижний = threshold - hysteresis/2. Переключение только при пересечении соответствующего порога.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| threshold | float | 0 | Пороговый уровень. |
| outputHigh | float | 1 | Значение выхода выше порога. |
| outputLow | float | 0 | Значение выхода ниже порога. |
| hysteresis | float | 0 | Ширина зоны гистерезиса. 0 = простой компаратор. |

### Примеры использования

1. **Меандр из синусоиды:** `Sine(1000) → Threshold(0) → Oscilloscope` — прямоугольные импульсы.
2. **Триггер Шмитта:** `Sine + Noise → Threshold(0, hysteresis: 0.3) → Oscilloscope` — без дребезга.
