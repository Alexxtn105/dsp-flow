# Визуализация

Блоки отображения сигналов: осциллограф, спектроанализатор, созвездие, водопад и числовые индикаторы.

---

## Осциллограф (Oscilloscope)

**ID:** `oscilloscope` | **Группа:** visualization | **Вход:** 4x real | **Выход:** null (визуализация)

### Назначение

Основной инструмент визуализации сигналов во временной области. Показывает амплитуду сигнала как функцию времени. Поддерживает до 4 независимых каналов для одновременного наблюдения нескольких сигналов.

### Алгоритм

Блок «прозрачный» (passthrough): передаёт массивы отсчётов всех подключённых каналов в OscilloscopeView без изменений. Данные упаковываются в {channels: [ch1, ch2, ch3, ch4]}.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| timeWindow | int | 10 | Ширина временного окна в миллисекундах. |

**Входы:** Канал 1, Канал 2, Канал 3, Канал 4

### Примеры использования

1. **Просмотр формы сигнала:**
   `Sine(1000) → Oscilloscope (Канал 1)` — классическая синусоида с периодом 1 мс.

2. **Сравнение входа и выхода фильтра:**
   `Sine + Noise → Summer → Oscilloscope (Канал 1)`, `Summer → LowpassFIR → Oscilloscope (Канал 2)` — зашумлённый vs. очищенный.

3. **Наблюдение за биениями:**
   `Sine(1000) + Sine(1050) → Summer → Oscilloscope` — биения с частотой 50 Гц.

## Фазовое созвездие (Constellation)

**ID:** `constellation` | **Группа:** visualization | **Вход:** complex | **Выход:** null (визуализация)

### Назначение

Диаграмма созвездия — визуализация цифрового модулированного сигнала. Каждый символ отображается как точка на плоскости I/Q. По степени «размытия» точек оценивается качество канала и работа демодулятора.

### Алгоритм

Принимает interleaved Float32Array [I0, Q0, I1, Q1, ...] и передаёт без изменений в ConstellationView для отрисовки.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| symbolRate | int | 1000 | Символьная скорость в бодах. |
| constellation | string | 'QPSK' | Тип созвездия: 'BPSK', 'QPSK', '8PSK', '16QAM'. |
| eyeDiagram | boolean | true | Отображение глазковой диаграммы. |

### Примеры использования

1. **Визуализация QPSK:**
   `PSKModulator(QPSK) → Constellation` — 4 чёткие точки.

2. **Оценка влияния шума:**
   `PSKModulator(QPSK) → [канал с шумом] → Constellation` — «размазанные» облака.

3. **Проверка синхронизации:**
   `PSKModulator(8PSK, sps=4) → TimingRecovery(sps=4) → PLL → Constellation` — 8 точек на окружности.

## Водопад (Waterfall)

**ID:** `waterfall` | **Группа:** visualization | **Вход:** real | **Выход:** null (визуализация)

### Назначение

Спектрограмма — двумерное отображение спектра во времени. По горизонтали — частота, по вертикали — время, цвет — амплитуда. Позволяет увидеть изменение частотного состава во времени: речь, ЧМ-сигналы, помехи, frequency hopping.

### Алгоритм

Идентичен SpectrumAnalyzer: кольцевой буфер → оконная функция → БПФ → магнитуда в дБ. Каждый кадр спектра передаётся в WaterfallView для накопления.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| fftSize | int | 2048 | Размер БПФ. Степень двойки. |
| windowFunction | string | 'blackman-harris' | Оконная функция. |
| colorMap | string | 'audition' | Цветовая карта. |
| speed | int | 1 | Скорость прокрутки. |

### Примеры использования

1. **Анализ ЧМ-сигнала:**
   `AMFMPMModulator(FM, deviation=500) → Waterfall` — траектория мгновенной частоты.

2. **Визуализация речи:**
   `AudioFile(speech.wav) → Waterfall(fftSize=4096)` — горизонтальные полосы формантов.

3. **Обнаружение помех:**
   `Signal → Waterfall(speed=2)` — кратковременные помехи видны как яркие полосы.

## Числовой индикатор (Numeric Indicator)

**ID:** `numeric-indicator` | **Группа:** visualization | **Вход:** real | **Выход:** null (визуализация)

### Назначение

Отображает мгновенное числовое значение вещественного сигнала. Аналог цифрового вольтметра: показывает последний отсчёт в виде числа. Полезен для контроля постоянных значений, уровней и отладки.

### Параметры

Нет настраиваемых параметров.

### Примеры использования

1. **Отображение константы:** `Constant(3.14) → NumericIndicator` — показывает «3.14».
2. **Контроль уровня:** `Sine(1000) → AmplitudeDetector → NumericIndicator`.
3. **Отладка:** `Signal → Gain(0.5) → NumericIndicator`.

## Комплексный числовой индикатор (Complex Numeric Indicator)

**ID:** `complex-numeric-indicator` | **Группа:** visualization | **Вход:** complex | **Выход:** null (визуализация)

### Назначение

Отображает мгновенное значение комплексного сигнала в формате Re + jIm. Показывает обе компоненты одновременно для отладки комплексной арифметики и проверки модуляторов/демодуляторов.

### Параметры

Нет настраиваемых параметров.

### Примеры использования

1. **Просмотр комплексной экспоненты:** `RefSine(1000) → ComplexNumericIndicator` — например, «0.707 + j0.707».
2. **Проверка арифметики:** `ComplexComposer(Re=3, Im=4) → ComplexNumericIndicator` — «3.000 + j4.000».
3. **Отладка демодулятора:** `PSKModulator(QPSK) → PLL → ComplexNumericIndicator` — значения I/Q около ±0.707.

## Многоканальный спектроанализатор (Multi-Channel Spectrum Analyzer)

**ID:** `multi-spectrum-analyzer` | **Группа:** visualization | **Вход:** 4x real | **Выход:** null (визуализация)

### Назначение

Четыре независимых спектроанализатора на одном экране. Позволяет одновременно сравнивать спектры нескольких сигналов: до и после фильтрации, разные ветви обработки, несколько каналов связи.

### Алгоритм

Каждый канал выполняет полный цикл спектрального анализа независимо: кольцевой буфер → оконная функция → БПФ → магнитуда → усреднение. Результаты упаковываются в {channels: [ch1, ch2, ch3, ch4]}.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| fftSize | int | 2048 | Размер БПФ для всех каналов. Степень двойки. |
| windowFunction | string | 'blackman-harris' | Оконная функция. |
| dBScale | boolean | true | Отображение в децибелах. |
| averaging | int | 5 | Кадров экспоненциального усреднения. |

**Входы:** Канал 1, Канал 2, Канал 3, Канал 4

### Примеры использования

1. **Сравнение до и после фильтрации:**
   `NoiseGenerator → MultiChannelSpectrumAnalyzer (Канал 1)`, `NoiseGenerator → LowpassFIR(1000) → MultiChannelSpectrumAnalyzer (Канал 2)`.

2. **Мониторинг нескольких сигналов:**
   `Sine(1000) → Канал 1`, `Sine(2000) → Канал 2`, `Sine(3000) → Канал 3`, `Sine(4000) → Канал 4`.
