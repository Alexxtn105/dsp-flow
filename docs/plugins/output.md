# Выход

Блоки вывода сигнала за пределы графа обработки.

---

## Динамик (Speaker)

**ID:** `speaker` | **Группа:** output | **Вход:** real | **Выход:** null (терминальный блок)

### Назначение

Воспроизводит входной сигнал через аудиосистему компьютера (динамики или наушники). Финальный блок в цепочке обработки для прослушивания синтезированных тонов, демодулированных сигналов, эффектов фильтрации и других звуковых результатов.

### Алгоритм

Блок «прозрачный» (passthrough): возвращает входной массив без изменений (или тишину при mute). Фактическое воспроизведение выполняется в DSPProcessor через Web Audio API (AudioWorklet или ScriptProcessorNode). В графе может быть только один блок Speaker.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| muted | boolean | false | Отключение звука. При true — тишина (массив нулей). |

### Примеры использования

1. **Воспроизведение тона:**
   `Sine(440) → Speaker` — нота «ля» первой октавы (440 Гц). Рекомендуется начинать с малой громкости!

2. **Прослушивание результата фильтрации:**
   `AudioFile(music.wav) → NotchFIR(50 Гц) → Speaker` — воспроизводит с подавленной наводкой 50 Гц.

3. **Демодуляция и прослушивание:**
   `AMFMPMModulator(FM) → FrequencyDiscriminator → Speaker` — восстанавливает модулирующий сигнал.

### Предупреждение

Амплитуда сигнала должна быть в пределах [-1, +1]. Значения за пределами вызовут клиппинг (искажения). Используйте блок Gain для масштабирования перед подачей на Speaker.
