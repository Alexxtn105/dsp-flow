# Фильтры

Блоки фильтрации и обработки сигналов: частотная фильтрация, изменение частоты дискретизации, задержка и спектральный анализ отдельных частот.

---

## Режекторный КИХ-фильтр (Notch FIR Filter)

**ID:** `notch-fir-filter` | **Группа:** filters | **Вход:** real | **Выход:** real

### Назначение

Удаляет (подавляет) сигнал в узкой полосе вокруг заданной частоты, пропуская все остальные частоты без изменений. Типичное применение — удаление помехи с известной частотой (сетевая наводка 50/60 Гц, тональная помеха, пилот-тон).

### Алгоритм

Фильтр строится методом спектральной инверсии: сначала проектируется полосовой КИХ-фильтр (windowed sinc) на нужную полосу, затем его коэффициенты инвертируются по формуле notch[n] = δ[n-center] - bandpass[n]. Полосовой фильтр нормализуется так, чтобы его коэффициент передачи на центральной частоте был равен 1.0. Порядок принудительно делается нечётным (Type I линейная фаза).

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| notchFrequency | float | 1000 | Центральная частота режекции в Гц. |
| bandwidth | float | 200 | Ширина полосы режекции в Гц. |
| order | int | 65 | Порядок фильтра. Рекомендуемый диапазон: 31–255. Автоматически округляется до нечётного. |
| windowFunction | string | 'hamming' | Оконная функция: 'rectangular', 'hamming', 'hanning', 'blackman', 'blackman-harris', 'nuttall', 'flattop'. |

### Примеры использования

1. **Удаление тональной помехи:**
   `Sine(1000) + NoiseGenerator → Summer → NotchFIR(1000Hz, bw=200) → Oscilloscope` — на осциллографе виден только шум.

2. **Подавление сетевой наводки 50 Гц:**
   `AudioFile → NotchFIR(50Hz, bw=10, order=127) → Speaker` — узкая полоса и высокий порядок точно убирают наводку.

3. **Каскад режекторных фильтров:**
   `Signal → NotchFIR(1000Hz) → NotchFIR(2000Hz) → NotchFIR(3000Hz) → Oscilloscope` — последовательное удаление нескольких помех.

## Полосовой КИХ-фильтр (Bandpass FIR Filter)

**ID:** `bandpass-fir-filter` | **Группа:** filters | **Вход:** real | **Выход:** real

### Назначение

Пропускает сигнал только в заданном диапазоне частот (от lowCutoff до highCutoff), подавляя всё, что ниже и выше этой полосы. Позволяет выделить полезный сигнал из смеси, ограничить полосу перед демодуляцией, разделить каналы в многоканальной системе.

### Алгоритм

Метод оконного sinc-фильтра (windowed sinc). Полосовой фильтр строится как разность двух ФНЧ: один с частотой среза highCutoff, другой — lowCutoff. Коэффициенты умножаются на выбранную оконную функцию.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| order | int | 64 | Порядок фильтра. Рекомендуемый диапазон: 16–512. |
| lowCutoff | float | 1000 | Нижняя граница полосы пропускания в Гц. |
| highCutoff | float | 3000 | Верхняя граница полосы пропускания в Гц. |
| windowFunction | string | 'hamming' | Оконная функция. |

### Примеры использования

1. **Выделение речевого диапазона:**
   `AudioFile → BandpassFIR(300Hz–3400Hz) → Speaker` — классический телефонный диапазон.

2. **Фильтрация перед демодуляцией:**
   `Sine(2000) + NoiseGenerator → Summer → BandpassFIR(1500–2500Hz) → Oscilloscope` — полосовой фильтр выделяет сигнал 2 кГц из шума.

## ФВЧ КИХ-фильтр (Highpass FIR Filter)

**ID:** `highpass-fir-filter` | **Группа:** filters | **Вход:** real | **Выход:** real

### Назначение

Пропускает частоты выше заданной частоты среза (cutoff), подавляя все низкочастотные составляющие. Используется для удаления постоянной составляющей (DC offset), низкочастотных дрейфов и выделения высокочастотных компонентов.

### Алгоритм

Строится на основе оконного sinc-фильтра методом спектральной инверсии ФНЧ: сначала проектируется ФНЧ, затем коэффициенты инвертируются для получения ФВЧ.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| order | int | 64 | Порядок фильтра. Рекомендуемый диапазон: 16–512. |
| cutoff | float | 1000 | Частота среза в Гц. |
| windowFunction | string | 'hamming' | Оконная функция. |

### Примеры использования

1. **Удаление DC offset:**
   `Constant(0.5) + Sine(1000) → Summer → HighpassFIR(10Hz) → Oscilloscope` — постоянная составляющая удалена.

2. **Выделение высокочастотного шума:**
   `AudioFile → HighpassFIR(5000Hz, order=128) → SpectrumAnalyzer` — на спектре видны только компоненты выше 5 кГц.

## ФНЧ КИХ-фильтр (Lowpass FIR Filter)

**ID:** `lowpass-fir-filter` | **Группа:** filters | **Вход:** real | **Выход:** real

### Назначение

Пропускает частоты ниже заданной частоты среза (cutoff), подавляя высокочастотные составляющие. Самый распространённый тип фильтра в ЦОС. Применяется для сглаживания, антиалиасинговой фильтрации перед децимацией, ограничения полосы и выделения огибающей.

### Алгоритм

Метод оконного sinc-фильтра (windowed sinc). Идеальный ФНЧ имеет импульсную характеристику sinc(2*fc*n), усечённую до конечного числа отсчётов и умноженную на оконную функцию.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| order | int | 64 | Порядок фильтра. Рекомендуемый диапазон: 16–512. |
| cutoff | float | 1000 | Частота среза в Гц. |
| windowFunction | string | 'hamming' | Оконная функция. Hamming ~43 дБ подавления, Blackman ~58 дБ, Blackman-Harris ~92 дБ. |

### Примеры использования

1. **Удаление высокочастотного шума:**
   `Sine(100) + NoiseGenerator → Summer → LowpassFIR(500Hz) → Oscilloscope` — шум подавлен.

2. **Антиалиасинговый фильтр перед децимацией:**
   `AudioFile → LowpassFIR(4000Hz, order=128) → DecimatorInterpolator(factor=4)` — предотвращение наложения спектров.

3. **Выделение огибающей AM-сигнала:**
   `AMFMPMModulator(AM) → AmplitudeDetector → LowpassFIR(100Hz) → Oscilloscope`.

## Преобразователь Гильберта (Hilbert Transformer)

**ID:** `hilbert-transformer` | **Группа:** filters | **Вход:** real | **Выход:** complex

### Назначение

Преобразует вещественный (real) сигнал в комплексный (аналитический). Аналитический сигнал — это z(t) = x(t) + j*H{x(t)}, где H{x(t)} — преобразование Гильберта (сдвиг фазы всех компонентов на 90°). У аналитического сигнала отсутствуют отрицательные частоты в спектре, что упрощает извлечение мгновенной амплитуды, частоты и фазы.

### Алгоритм

КИХ-фильтр с коэффициентами преобразования Гильберта: h[n] = 2/(π*n) для нечётных n, h[n] = 0 для чётных n и n = 0. Коэффициенты умножаются на окно Блэкмана. Q-компонента — результат свёртки, I-компонента — задержанный на (N-1)/2 отсчётов входной сигнал.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| order | int | 64 | Порядок фильтра Гильберта. Рекомендуемый диапазон: 31–255. |
| phaseShift | float | 90 | Сдвиг фазы в градусах (зарезервирован). |

### Примеры использования

1. **Проверка аналитического сигнала:**
   `Sine(1000) → HilbertTransformer → ComplexMagnitude → Oscilloscope` — магнитуда = const для чистой синусоиды.

2. **Огибающая AM-сигнала:**
   `AMFMPMModulator(AM, carrier=5000Hz) → HilbertTransformer → ComplexMagnitude → LowpassFIR(100Hz) → Oscilloscope`.

## Фильтр Герцеля (Goertzel Filter)

**ID:** `goertzel-filter` | **Группа:** filters | **Вход:** real | **Выход:** real

### Назначение

Вычисляет мощность (магнитуду) сигнала на одной заданной частоте. Аналог одного «бина» ДПФ/БПФ, но значительно эффективнее, когда нужно проанализировать лишь одну-две частоты. Классические применения: детектирование DTMF-тонов, определение наличия пилот-тона.

### Алгоритм

Рекурсивный метод вычисления одного элемента ДПФ. На каждом отсчёте: s0 = x[n] + coeff * s1 - s2, где coeff = 2*cos(2π*k/N). После N отсчётов вычисляется magnitude = sqrt(Re^2 + Im^2) / (N/2). Сложность: O(N) для одной частоты.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| targetFrequency | float | 1000 | Частота анализа в Гц. |
| N | int | 256 | Размер блока анализа. Частотное разрешение: Δf = sampleRate / N. |

### Примеры использования

1. **Измерение мощности тона:**
   `Sine(1000, amplitude=0.5) → Goertzel(1000Hz, N=256) → NumericIndicator` — покажет ~0.5.

2. **Детектирование наличия сигнала:**
   `AudioFile → Goertzel(440Hz, N=1024) → Threshold(0.1) → NumericIndicator` — определяет присутствие ноты «Ля».

## Фильтр Ремеза (Remez Filter)

**ID:** `remez-filter` | **Группа:** filters | **Вход:** real | **Выход:** real

### Назначение

Полосовой фильтр, спроектированный алгоритмом Ремеза (Parks-McClellan). В отличие от оконного метода, алгоритм минимизирует максимальную ошибку (equiripple design): пульсации равномерно распределены. Это даёт оптимальный фильтр при заданном порядке.

### Алгоритм

Итерационный метод Паркса-Макклеллана. На каждой итерации находятся экстремумы, коэффициенты пересчитываются до сходимости. Порядок принудительно делается нечётным (Type I).

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| order | int | 101 | Порядок фильтра. Рекомендуемый диапазон: 31–501. |
| lowCutoff | float | 1000 | Нижняя граница полосы пропускания в Гц. |
| highCutoff | float | 3000 | Верхняя граница полосы пропускания в Гц. |

### Примеры использования

1. **Точная полосовая фильтрация:**
   `AudioFile → Remez(1000–3000Hz, order=101) → SpectrumAnalyzer` — очень крутые скаты и равномерные пульсации.

2. **Сравнение с оконным фильтром:**
   При одинаковом порядке Ремез показывает лучшее подавление за полосой пропускания.

## Линия задержки (Delay Line)

**ID:** `delay-line` | **Группа:** filters | **Вход:** real | **Выход:** real

### Назначение

Задерживает входной сигнал на заданное количество отсчётов. Фундаментальный строительный блок для гребёнчатых фильтров, эхо-эффектов, компенсации групповой задержки и корреляционного анализа.

### Алгоритм

Реализована через кольцевой буфер (circular buffer) размером N. На каждом отсчёте считывается задержанное значение и записывается новое. O(1) на отсчёт. При изменении длины задержки буфер пересоздаётся с копированием хвоста.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| delaySamples | int | 100 | Количество отсчётов задержки. Задержка в секундах = delaySamples / sampleRate. |

### Примеры использования

1. **Простое эхо:**
   `Sine(1000) → DelayLine(4800) → Summer(с оригиналом) → Oscilloscope` — задержка 100 мс создаёт эхо.

2. **Компенсация задержки фильтра:**
   DelayLine(order/2) компенсирует групповую задержку КИХ-фильтра.

## Децимация/Интерполяция (Decimator/Interpolator)

**ID:** `decimator-interpolator` | **Группа:** filters | **Вход:** real | **Выход:** real

### Назначение

Изменяет частоту дискретизации сигнала: уменьшает (децимация) или увеличивает (интерполяция) количество отсчётов. Необходимо, когда разные части системы работают на разных частотах.

### Алгоритм

- **Децимация:** антиалиасинговый ФНЧ (sinc + Хэмминг) → прореживание каждого factor-го отсчёта.
- **Интерполяция:** zero-stuffing (вставка нулей) с компенсацией усиления → антиимиджинговый ФНЧ.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| mode | string | 'decimate' | Режим: 'decimate' или 'interpolate'. |
| factor | int | 2 | Коэффициент изменения частоты. Диапазон: 1–16. |
| filterEnabled | bool | true | Включить встроенный фильтр. |

### Примеры использования

1. **Снижение частоты дискретизации:**
   `AudioFile(48kHz) → DecimatorInterpolator(decimate, factor=4) → SpectrumAnalyzer` — прорежен до 12 кГц.

2. **Многоступенчатая децимация:**
   `Signal → DecimatorInterpolator(decimate, 4) → DecimatorInterpolator(decimate, 4)` — двухступенчатая децимация в 16 раз.

## CIC-фильтр (CIC Filter)

**ID:** `cic-filter` | **Группа:** filters | **Вход:** real | **Выход:** real

### Назначение

Каскадный интегратор-гребёнка — специализированный фильтр для изменения частоты дискретизации без операций умножения. Крайне эффективен при больших коэффициентах децимации (10x и более). Широко применяется в SDR-приёмниках.

### Алгоритм

Структура: каскад из N интеграторов → изменение частоты → каскад из N гребёнок (comb). Интеграторы реализованы на Int32Array с wrapping-арифметикой. Частотная характеристика CIC — sinc^N(f).

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| stages | int | 3 | Количество каскадов. Диапазон: 1–6. |
| decimationFactor | int | 4 | Коэффициент децимации/интерполяции (R). Диапазон: 2–64. |
| mode | string | 'decimate' | Режим: 'decimate' или 'interpolate'. |

### Примеры использования

1. **Быстрая децимация в SDR:**
   `Signal → CIC(stages=4, R=16, decimate) → FIRFilter → SpectrumAnalyzer` — CIC снижает частоту в 16 раз, КИХ-фильтр компенсирует спад АЧХ.

2. **Интерполяция:**
   `Signal(12kHz) → CIC(stages=3, R=4, interpolate) → LowpassFIR → Speaker`.

## КИХ-фильтр (FIR Filter)

**ID:** — (фабричная функция `createFIRProcessor`) | **Группа:** filters

### Назначение

Фабрика процессоров для КИХ-фильтров: ФНЧ (lowpass), ФВЧ (highpass) и полосовой (bandpass). Используется плагинами LowpassFIR, HighpassFIR и BandpassFIR.

### Алгоритм

Метод оконного sinc (windowed sinc design): идеальная импульсная характеристика sinc, масштабированная по частоте среза, умножается на оконную функцию. Фильтрация через кольцевой буфер. КИХ-фильтры гарантируют линейную фазовую характеристику при симметричных коэффициентах.

---

## БИХ-фильтр (IIR Filter)

**ID:** `iir-filter` | **Группа:** filters | **Вход:** real | **Выход:** real

### Назначение

Фильтр с бесконечной импульсной характеристикой (рекурсивный). Обеспечивает крутые скаты при малом порядке: фильтр 4-го порядка Баттерворта даёт скат 80 дБ/декаду. Недостаток — нелинейная фазовая характеристика.

### Алгоритм

Два дизайна:
- **Баттерворт (Butterworth):** Максимально плоская АЧХ, скат order * 20 дБ/декаду.
- **Чебышев I (Chebyshev Type I):** Более крутой скат с равномерными пульсациями в полосе пропускания.

Аналоговый прототип → билинейное преобразование с предварительным варпингом. Реализация — каскад биквадратных секций (biquad / SOS).

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| filterDesign | string | 'butterworth' | Тип: 'butterworth' или 'chebyshev1'. |
| filterType | string | 'lowpass' | Тип фильтрации: 'lowpass' или 'highpass'. |
| cutoffFrequency | float | 1000 | Частота среза в Гц. |
| order | int | 4 | Порядок фильтра. Диапазон: 1–10. |
| ripple | float | 1 | Пульсации в дБ (только для Чебышева I). |

### Примеры использования

1. **Резкий ФНЧ малым порядком:**
   `NoiseGenerator → IIRFilter(butterworth, lowpass, 2000Hz, order=6) → SpectrumAnalyzer` — скат 120 дБ/декаду.

2. **ФВЧ для удаления DC:**
   `AudioFile → IIRFilter(butterworth, highpass, 20Hz, order=2) → Speaker` — убирает DC и инфразвук.
