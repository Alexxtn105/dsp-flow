# Детекторы

Блоки извлечения параметров сигнала: фаза, частота, амплитуда, синхронизация. Включают детекторы, демодуляторы, PLL и символьную синхронизацию.

---

## Фазовый детектор (Phase Detector)

**ID:** `phase-detector` | **Группа:** detectors | **Вход:** complex | **Выход:** real

### Назначение

Извлекает мгновенную фазу из комплексного (I/Q) сигнала и представляет её в одном из нескольких форматов. Фаза — это угол вектора (I, Q) на комплексной плоскости.

### Алгоритм

1. φ[n] = atan2(Q, I), диапазон (−π, π].
2. Развёртка фазы (phase unwrapping): Δφ корректируется на ±2π при |Δφ| > π.
3. Накопление: accumPhase += Δφ.
4. Преобразование в выбранный формат и масштабирование.

Защита: при |z| < 1e-10 фаза не определена — выводится последнее накопленное значение.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| referenceFrequency | float | 1000 | Опорная частота (информационная), Гц. |
| sensitivity | float | 1.0 | Коэффициент усиления выхода. Диапазон: 0.01–100. |
| outputRange | string | '±180°' | Формат: '±180°' (градусы, накопленная), '0-360°' (градусы, свёрнутая), '0-2π' (радианы, свёрнутая), '±π' (радианы, накопленная). |

### Примеры использования

1. **Визуализация линейного роста фазы:**
   `RefSine(1000) → ComplexComposer → PhaseDetector(±180°) → Oscilloscope` — линейно нарастающая фаза.

2. **Пилообразная фаза:**
   `RefSine(1000) → ComplexComposer → PhaseDetector(0-360°) → Oscilloscope` — оборачивается каждые 360°.

3. **Демодуляция фазовой модуляции:**
   `AMFMPMModulator(PM) → HilbertTransformer → PhaseDetector(±π) → Oscilloscope` — извлечённая фаза повторяет модулирующий сигнал.

## Частотный детектор (Frequency Detector)

**ID:** `frequency-detector` | **Группа:** detectors | **Вход:** complex | **Выход:** real

### Назначение

Определяет мгновенную частоту комплексного сигнала и выделяет компоненты в заданной полосе вокруг центральной частоты. Полезен для слежения за частотой конкретной компоненты в зашумлённом сигнале.

### Алгоритм

1. φ[n] = atan2(Q, I)
2. Δφ = unwrap(φ[n] − φ[n−1])
3. f = Δφ * sampleRate / (2π)
4. deviation = f − centerFrequency
5. Если |deviation| > bandwidth/2, выход = 0.
6. out = deviation * sensitivity

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| centerFrequency | float | 1000 | Центральная частота, Гц. |
| bandwidth | float | 100 | Ширина полосы пропускания, Гц. |
| sensitivity | float | 1.0 | Коэффициент усиления выхода. |

### Примеры использования

1. **Слежение за частотой:**
   `RefSine(1000) → ComplexComposer → FrequencyDetector(fc=1000, BW=100) → Oscilloscope` — выход около нуля.

2. **Детекция ЧМ-модуляции в узкой полосе:**
   `AMFMPMModulator(FM, fc=1000, dev=30) → HilbertTransformer → FrequencyDetector(fc=1000, BW=100) → Oscilloscope` — восстановленный модулирующий сигнал.

## Амплитудный детектор (Amplitude Detector)

**ID:** `amplitude-detector` | **Группа:** detectors | **Вход:** real | **Выход:** real

### Назначение

Выделяет огибающую (envelope) амплитуды входного сигнала. Работает аналогично детектору уровня в аналоговых компрессорах и лимитерах.

### Алгоритм

Экспоненциальное сглаживание с раздельными постоянными времени:
- Если |x[n]| > env[n-1]: env[n] = env[n-1] + αa * (|x[n]| − env[n-1]) (атака)
- Иначе: env[n] = env[n-1] + αr * (|x[n]| − env[n-1]) (восстановление)

Коэффициенты: α = 1 − exp(−1 / (sampleRate * time_сек)).

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| attackTime | float | 1 | Время атаки в мс. Диапазон: 0.01–50 мс. |
| releaseTime | float | 50 | Время восстановления в мс. Диапазон: 1–1000 мс. |

### Примеры использования

1. **Визуализация огибающей аудио:**
   `AudioFile → AmplitudeDetector(attack=1, release=50) → Oscilloscope`.

2. **Детекция AM-модуляции:**
   `AMFMPMModulator(AM) → AmplitudeDetector(attack=0.1, release=10) → Oscilloscope` — восстановление модулирующего сигнала.

3. **Измерение уровня:**
   `Sine(1000) → AmplitudeDetector(attack=5, release=200) → NumericIndicator`.

## ФАПЧ (Phase-Locked Loop / PLL)

**ID:** `pll` | **Группа:** detectors | **Вход:** complex | **Выход:** complex + real

### Назначение

Классическая петля фазовой автоподстройки частоты 2-го порядка с посэмпловой обратной связью. Захватывает фазу и частоту входного сигнала.

### Алгоритм

1. **Фазовый детектор:** atan2(inQ*ncoI - inI*ncoQ, inI*ncoI + inQ*ncoQ)
2. **Петлевой фильтр (PI):** u(n) = Kp*e(n) + Ki*∑e(k), где Kp = 2*ζ*ωn, Ki = ωn^2 (формулы Гарднера)
3. **NCO:** фазовый аккумулятор, управляемый суммой базовой частоты и выхода петлевого фильтра

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| centerFrequency | float | 1000 | Начальная частота NCO, Гц. |
| bandwidth | float | 50 | Полоса захвата петли, Гц. ωn = 2π*BW. |
| damping | float | 0.707 | Коэффициент демпфирования ζ. 0.707 — оптимум Баттерворта. |

**Выходы:**
- Выход 0: complex — выход NCO (восстановленная несущая, interleaved I/Q)
- Выход 1: real — фазовая ошибка (радианы)

### Примеры использования

1. **Захват и слежение за синусоидой:**
   `RefSine(1000) → ComplexComposer → PLL(fc=1000, BW=50) → ComplexMagnitude → Oscilloscope` — PLL захватывает тон, фазовая ошибка стремится к нулю.

2. **Восстановление несущей в PSK-приёмнике:**
   `PSKModulator(QPSK, sps=4) → TimingRecovery(sps=4) → PLL(fc=0, BW=30) → Constellation` — PLL компенсирует фазовый сдвиг.

3. **Анализ захвата петли:**
   `RefSine(1050) → ComplexComposer → PLL(fc=1000, BW=100) → [фазовая ошибка] → Oscilloscope` — видно затухание ошибки.

## АМ/ЧМ/ФМ демодулятор (AM/FM/PM Demodulator)

**ID:** `amfmpm-demodulator` | **Группа:** detectors | **Вход:** real | **Выход:** real

### Назначение

Извлекает информационный сигнал из модулированного колебания. На вход подаётся действительный сигнал, внутри формируется аналитический через преобразование Гильберта (31-точечный КИХ-фильтр с окном Хэмминга).

### Алгоритм

- **AM:** огибающая = √(I^2 + Q^2), затем DC-блокировка (y[n] = x[n] - x[n-1] + 0.995*y[n-1]).
- **FM:** мгновенная частота через conj(z[n-1])*z[n], Δφ = atan2(Im, Re), f = Δφ * sampleRate / (2π).
- **PM:** мгновенная фаза = atan2(Q, I), значения в радианах (-π до π).

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| modulationType | string | 'AM' | Тип демодуляции: 'AM', 'FM', 'PM'. |
| carrierFrequency | float | 10000 | Частота несущей, Гц (информационная). |

### Примеры использования

1. **Демодуляция FM:**
   `AMFMPMModulator(FM, fc=10000, dev=5000) → AMFMPMDemodulator(FM) → Oscilloscope` — восстановленный модулирующий сигнал.

2. **Демодуляция AM:**
   `AMFMPMModulator(AM) → AMFMPMDemodulator(AM) → Oscilloscope` — детектор огибающей.

## Частотный дискриминатор (Frequency Discriminator)

**ID:** `frequency-discriminator` | **Группа:** detectors | **Вход:** complex | **Выход:** real

### Назначение

Вычисляет мгновенную частоту комплексного сигнала путём дифференцирования фазы. Выдаёт «сырое» значение частоты без фильтрации — универсальный инструмент для анализа.

### Алгоритм

1. φ[n] = atan2(Q, I)
2. Δφ = φ[n] − φ[n−1] с развёрткой (±2π при |Δφ| > π)
3. f = Δφ * sampleRate / (2π) [Гц]

**Отличие от FrequencyDetector:** нет полосовой фильтрации и масштабирования.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| outputMode | string | 'deviation' | 'deviation' — отклонение от centerFrequency; 'absolute' — абсолютная частота. |
| centerFrequency | float | 1000 | Центральная частота (вычитается в режиме deviation), Гц. |

### Примеры использования

1. **Демодуляция ЧМ:**
   `AMFMPMModulator(FM, fc=1000, dev=200) → HilbertTransformer → FrequencyDiscriminator(deviation, fc=1000) → Oscilloscope` — отклонение частоты ±200 Гц.

2. **Измерение абсолютной частоты:**
   `RefSine(1000) → FrequencyDiscriminator(absolute) → NumericIndicator` — показывает ~1000 Гц.

## Символьная синхронизация (Timing Recovery)

**ID:** `timing-recovery` | **Группа:** detectors | **Вход:** complex | **Выход:** complex

### Назначение

Восстанавливает оптимальные моменты стробирования в цифровом приёмнике. На входе — поток с избыточной дискретизацией, на выходе — по одному отсчёту на символ в наилучший момент. Ключевой блок в цепочке демодуляции.

### Алгоритм

Gardner Timing Error Detector (TED) — некогерентный детектор ошибки синхронизации:
- Ошибка: e = Re{(prev_symbol - current_symbol) * conj(midpoint)}
- Петлевой PI-фильтр плавно подстраивает интервал стробирования.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| samplesPerSymbol | int | 4 | Количество отсчётов на символ. Типичные значения: 2, 4, 8. |
| loopBandwidth | float | 0.01 | Нормированная полоса петли. Диапазон: 0.001–0.05. |
| damping | float | 0.707 | Коэффициент демпфирования. |

### Примеры использования

1. **Демодуляция QPSK:**
   `PSKModulator(QPSK, sps=4) → TimingRecovery(sps=4, BW=0.01) → PLL → Constellation` — тактовая синхронизация + фазовая коррекция.

2. **Демодуляция 8-PSK:**
   `PSKModulator(8PSK, sps=8) → BandpassFIR → TimingRecovery(sps=8, BW=0.005) → Constellation` — сниженная loopBandwidth для уменьшения джиттера.
