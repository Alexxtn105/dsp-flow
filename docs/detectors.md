# Детекторы

Блоки извлечения информации из сигнала: частота, фаза, амплитуда, демодуляция, синхронизация.

## Фазовый детектор

| | |
|---|---|
| **ID** | `phase-detector` |
| **Иконка** | `dsp-phase-detect` |
| **Вход → Выход** | complex → real |

Извлечение фазы комплексного сигнала с развёрткой (unwrapping).

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `referenceFrequency` | 1000 | Опорная частота, Гц |
| `sensitivity` | 1.0 | Чувствительность |
| `outputRange` | `'±180°'` | Диапазон: `±180°`, `±π`, `0-360°`, `0-2π` |

### Алгоритм

`φ = atan2(Q, I)` с развёрткой фазы (phase unwrapping): накопление дельт, приведённых к диапазону `[-π, π]`. Выход масштабируется в выбранный диапазон.

## Частотный детектор

| | |
|---|---|
| **ID** | `frequency-detector` |
| **Иконка** | `dsp-freq-detect` |
| **Вход → Выход** | complex → real |

Определение мгновенной частоты сигнала.

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `centerFrequency` | 1000 | Центральная частота, Гц |
| `bandwidth` | 100 | Полоса пропускания, Гц |
| `sensitivity` | 1.0 | Чувствительность |

### Алгоритм

Производная фазы: `f_мгн = dφ/dt · Fs/(2π)`. Значения за пределами полосы `[fc - BW/2, fc + BW/2]` обнуляются.

## Амплитудный детектор

| | |
|---|---|
| **ID** | `amplitude-detector` |
| **Иконка** | `dsp-amp-detect` |
| **Вход → Выход** | real → real |

Детектор огибающей с асимметричными постоянными времени.

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `attackTime` | 1 | Время атаки, мс |
| `releaseTime` | 50 | Время спада, мс |

### Алгоритм

Огибающая со сглаживанием: если `|x| > envelope` — используется коэффициент атаки, иначе — спада. Коэффициенты: `α = 1 - exp(-1/(Fs·T·0.001))`.

## Частотный дискриминатор

| | |
|---|---|
| **ID** | `frequency-discriminator` |
| **Иконка** | `dsp-freq-discrim` |
| **Вход → Выход** | complex → real |

Мгновенная частота без фильтрации и усреднения.

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `outputMode` | `'deviation'` | `deviation` — отклонение от центральной, `absolute` — абсолютная частота |
| `centerFrequency` | 1000 | Центральная частота, Гц |

### Алгоритм

Производная фазы: `Δφ = atan2(Q·I_prev - I·Q_prev, I·I_prev + Q·Q_prev)`. Частота: `f = Δφ·Fs/(2π)`.

## ФАПЧ (PLL)

| | |
|---|---|
| **ID** | `pll` |
| **Иконка** | `dsp-pll` |
| **Вход → Выход** | complex → complex + real (2 выхода) |
| **Выходы** | «NCO (I/Q)», «Фазовая ошибка» |

Фазовая автоподстройка частоты — петля обратной связи 2-го порядка.

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `centerFrequency` | 1000 | Центральная частота NCO, Гц |
| `bandwidth` | 50 | Полоса захвата, Гц |
| `damping` | 0.707 | Коэффициент демпфирования |

### Алгоритм

1. **Фазовый детектор**: `e = atan2(Q_in·I_nco - I_in·Q_nco, I_in·I_nco + Q_in·Q_nco)`
2. **Петлевой фильтр (PI)**: `Kp = 2ζωn/Fs`, `Ki = ωn²/Fs²`, где `ωn = 2π·BW`
3. **NCO**: `φ += 2π·fc/Fs + loopOutput`, выход — `I = cos(φ)`, `Q = sin(φ)`

Второй выход — сигнал фазовой ошибки (для мониторинга захвата).

## АМ/ЧМ/ФМ демодулятор

| | |
|---|---|
| **ID** | `amfmpm-demodulator` |
| **Иконка** | `dsp-demodulator` |
| **Вход → Выход** | real → real |

Демодуляция AM/FM/PM сигналов через формирование аналитического сигнала.

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `modulationType` | `'AM'` | Тип: `AM`, `FM`, `PM` |
| `carrierFrequency` | 10000 | Частота несущей, Гц |

### Алгоритм

Используется 15-точечный КИХ-фильтр Гильберта (окно Хэмминга) для формирования аналитического сигнала `z(t) = I(t) + j·Q(t)`:

- **АМ**: огибающая `√(I² + Q²)` с DC-блокировкой (однополюсный ФВЧ, α = 0.995)
- **ЧМ**: мгновенная частота `(I·dQ - Q·dI)/(I² + Q²)·Fs/(2π)`
- **ФМ**: фаза `atan2(Q, I)`

## Символьная синхронизация

| | |
|---|---|
| **ID** | `timing-recovery` |
| **Иконка** | `dsp-timing` |
| **Вход → Выход** | complex → complex |

Восстановление тактовой синхронизации (Timing Recovery) для цифровой демодуляции.

### Параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `samplesPerSymbol` | 4 | Количество отсчётов на символ |
| `loopBandwidth` | 0.01 | Полоса петли (нормализованная) |
| `damping` | 0.707 | Коэффициент демпфирования |

### Алгоритм

**Gardner TED** (Timing Error Detector):

1. **Стробирование**: выборка сигнала в моменты, кратные периоду символа
2. **Середина**: сохранение значения посередине между символами
3. **Ошибка**: `e = Re{(prev_symbol - current_symbol)·conj(midpoint)}`
4. **PI-петля**: `integrator += Ki·e`, `period = SPS + Kp·e + integrator`
5. Период ограничен диапазоном `[0.5·SPS, 1.5·SPS]`

Выход — оптимально стробированные символы (пригодны для визуализации созвездия).
