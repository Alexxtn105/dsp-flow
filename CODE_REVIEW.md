## 2. Исправленные проблемы (ветка `fix/code_review`)

### 2.1. Сумматор — реализована нормализация

**Файл:** `SummerPlugin.js`

Реализована обработка параметра `normalization`:
- `'none'` — без нормализации (поведение по умолчанию)
- `'average'` — деление суммы на количество активных входов
- `'peak'` — нормализация к пиковому значению чанка

### 2.2. Перемножитель — реализовано деление

**Файл:** `MultiplierPlugin.js`

Реализована обработка параметра `operation`:
- `'multiply'` — перемножение (поведение по умолчанию)
- `'divide'` — деление с защитой от деления на ноль (результат = 0)

### 2.3. Фазовый детектор — полная обработка outputRange

**Файл:** `PhaseDetectorPlugin.js`

Реализованы все четыре диапазона:
- `'±180°'` — накопленная фаза в градусах
- `'±π'` — накопленная фаза в радианах
- `'0-360°'` — фаза, обёрнутая в диапазон [0, 360°]
- `'0-2π'` — фаза, обёрнутая в диапазон [0, 2π]

Также задействован параметр `sensitivity` — масштабирует выходное значение.

### 2.4. Спектроанализатор — реализованы dBScale и averaging

**Файл:** `SpectrumAnalyzerPlugin.js`

- `dBScale: true/false` — выбор между дБ и линейной магнитудой
- `averaging` — экспоненциальное усреднение спектра (alpha = 1/N кадров)
- Удалён неиспользуемый параметр `frequencyRange` (обрезка спектра — задача визуализатора)

### 2.5. Осциллограф — убраны неиспользуемые параметры

**Файл:** `OscilloscopePlugin.js`

Удалены `samplingRate` и `channels` из `defaultParams`. Оставлен `timeWindow` — используется визуализатором.

### 2.6. Фазовое созвездие — без изменений

Процессор-заглушка корректен для блоков визуализации — данные отображаются React-компонентом.

### 2.7. Скользящее БПФ — добавлен выбор оконной функции

**Файл:** `SlidingFFTPlugin.js`

Добавлен параметр `windowFunction: 'hanning'` в `defaultParams`. Процессор теперь читает его вместо захардкоженного `WindowFunctions.hanning`.

### 2.8. Сумматор — корректное отображение массива weights

**Файл:** `BlockParamsDialog.jsx`

Добавлен тип `'array'` в `getInputType()`. Массивы отображаются как текстовое поле с comma-separated значениями и парсятся обратно в массив чисел.

### 2.9. Специализированные фильтры — скрыт filterType

**Файлы:** `FIRFilterPlugin.js`, `BandpassFIRPlugin.js`, `LowpassFIRPlugin.js`, `HighpassFIRPlugin.js`

- `createFIRProcessor(fixedFilterType)` принимает фиксированный тип фильтра
- Специализированные фильтры вызывают `createFIRProcessor('bandpass')` / `createFIRProcessor('lowpass')` / `createFIRProcessor('highpass')`
- `filterType` убран из их `defaultParams` — больше не отображается в диалоге
- Универсальный КИХ-фильтр продолжает показывать dropdown `filterType`

### 2.10. Частотный детектор — реализованы centerFrequency, bandwidth, sensitivity

**Файл:** `FrequencyDetectorPlugin.js`

Процессор теперь:
- Вычисляет отклонение мгновенной частоты от `centerFrequency`
- Обнуляет выход, если частота вне полосы `centerFrequency ± bandwidth/2`
- Масштабирует выход на `sensitivity`

### 2.11. Фильтр Герцеля — убран дублирующий samplingRate

**Файл:** `GoertzelFilterPlugin.js`

Удалён `samplingRate` из `defaultParams`. Процессор теперь использует системный `sampleRate` из контекста params.
